# ADR 0014：Epic 1 一枪一刃迁移

状态：实现，待 PR 审查与操作者手感验收。

## 范围与依据

实现 GitHub #101–#106，以 `NARRATIVE_FOUNDATION.md` 8.1/8.2 的单手黑晶手枪与意志短刃为准。保留用户新加入的两张设计稿及尺寸，并按用户最新要求放宽面数预算。第 8 节的历史“心智卡宾”列表保留，实际按 issue 明确的手枪规格实现。不扩展心魔、赐福、局外成长或终局。

## 决策

1. 单枪 `Weapon.data` 与单刃 `MeleeWeapon.blade_data` 替代槽位，移除切枪、切刀、倍率和独立 Hammer。保留既有 Stats 技能组件、命中反馈与三关流程。
2. 重组为无限能量补充；基础 8 发/0.85 秒，已有容量/重组速度增益继续生效。冲刺不取消重组，避免空匣被冲刺永久卡住。数值、动画和完成信号共用一个进度。
3. 遵循 issues #101/#102/#103 的纠偏评论：在 Blender 制作原创 GLB，不使用 CSG。以 SUPERHOT 为建模风格参考，保留不规则矿物切面、硬朗轮廓与 Shade Flat。以第 8 节和最新多视角设计稿为准：手枪总长 220mm、高 135mm、宽 32mm；短刃长 400mm、刃宽 40mm、厚 15mm。面数依当前创作要求放宽，优先轮廓、矿物切面和黑曜石质感，实际源面与三角数分别登记。图内冲突尺寸及护圈以正文规格为准。四个手枪部件各有中心枢轴，根原点在握把中心。源码、`.blend` 与统计见 `tools/epic1_models/`。
4. 弹反用组件自己的 Area 与投射物扫掠检测，不由武器向上查找关卡。反弹后 source 转玩家，并移除原敌方排除列表，才能反杀发射者。
5. 短刃生效帧触发敲钟，保留节拍时间源、普通/完美值和 Boss 一击核心规则。需面向钟且无遮挡，站在区域内背对钟无效。
6. 遵循 #105 最新的完整第一人称身躯正文，演进现有完整 24 骨身体，复用原角色 GLB、主角晶体材质与预切碎片；头部只投影，胸腹、双臂和走动双腿可见，移除独立 `left_hand_view`。按当前创作要求，裂缝沿原有晶体切面的真实接缝，统一黑色，不使用彩色或琥珀发光；1 级左腕细裂、2 级延至手背胸锁骨、3 级胸臂微幅剥片、4 级全身深裂；禁止程序造假肢或重捏人体。原碎片库的胸部只有一个完整块，胸部脱嵌由着色器移动既有切面，手臂使用原预切片；不重建人体形状或增加三角形。裂痕渲染副本只展开原索引以追加真实接缝属性，0 级恢复原网格。通过 `Events.sin_defeated(count)` 预留未来流程。测试台数字键属于调试，不在正式地图绑定，不擅自把现有小关数当心魔数。
7. 原始模型素材、历史设计与截图保留；删除运行时旧武器资源和专属死逻辑。旧测试文件名可保留以维持审查入口，但内容迁移到新体系。

## 验收

直接运行 `tests/combat_bench.tscn`，两分钟路线：点射8发看自动重组 → R主动重组/冲刺 → 木桩4米吸附 → 迎慢弹挥刃反杀 → 走近时钟按节拍挥刃 → 低头查看胸腹/双腿与完整人影 → 0–4切换全身裂痕。Esc释放鼠标后可点击裂痕按钮，左键重新捕获。

无界面检查：`tests/obsidian_pistol_test.tscn`、`tests/mind_blade_test.tscn`、`tests/body_awareness_test.tscn` 及迁移后的原有测试；fixture用 `--fixed-fps 60` 验证两次回放一致。武器节奏、伤害与输入改变会改变原型fixture哈希，不能声称与旧版哈希相同。

合并仍遵守 CONTRIBUTING：受保护文件、删除与fixture变更交由 Kyrie 审查，不自动合并。
