## 现在的行为

- 审判之瞳原死亡回调仍逐块调用56次凸碰撞生成，普通恐惧小怪的前轮缓存未覆盖这个独立视觉脚本。现在Boss加载时准备并复用 `FearShatter` 的56份碰撞形状，保留完整独立刚体、当前姿态、领域剥夺、实际碎片拾取和门扉。
- 狂暴尖塔增加定向齐射与三点晶刺，循环为齐射→裂地→散射→晶刺→旋涡；目标超过9米时近身旋涡改为齐射。Boss仍为1050生命，没有提高小兵强度。
- 齐射预警1.1秒，起手锁向，三轮各5颗可弹反的一次反弹晶弹，间隔0.28秒，10基础伤/发、24米/秒。晶刺在起手锁定玩家脚下及左右4.5米的有效地面，最远40米、实体视线可达；预警1.2秒、半径1.6米、18基础伤，每处只命中一次。离圈、真实跳跃至脚底高于0.45米或WORLD掩体可规避。新伤害沿用领域倍率，结束保留1.5秒反击窗口；暂停、局部时间与预警剥夺继续生效，Boss/目标死亡或退出清除所属威胁。
- 用户确认是“从敌人脚下向外扩散的攻击波”。实际哀嚎者哭波及Boss潮波统一 `Color(0.06,0.42,0.95)` 的蓝色无光照发光材质，保留原时机、伤害与减益。本轮未从代码中证实某个黄色常量是原因，不把色差推测写成已复现的根因。
- 恐惧玩家坠落改为固定扣30点实际生命，并返回最近稳定静态平台。每0.15秒检查脚下及四侧支撑，排除翻转板；恢复前检查支撑与胶囊占位，落点被挡则查入口九个候选。恢复取消冲刺/吸附/外部冲量并清零速度，0.3秒防重；Area和-12米高度检测共用这一过程。无敌、护盾和复活不能抵消固定代价；扣至0生命时才正常死亡，敌人坠落仍致死。HUD显示2.5秒扣血与返回提示，死亡仍有死因、按钮和R重开。
