# Sloth 红晶体敌人备用设计

2026-11-04。本轮用户授权：用仓库现有红色晶体人形为基准增加外观与技能，随后明确仅存放备用，主游戏不更新。下述实现、编排和参数均只存在于还原后的独立副本；不是最终平衡，也不代表完整第一层已完成。

原设计参照 [Sloth LDD](../../docs/levels/SLOTH_LEVEL_DESIGN.md)；本轮红晶体方案仅作为其敌人部分的备用实验。旧Boss仍为旧原型，未改成沉眠巨像。

## 三类敌人与模型细节

| 敌人 | 一眼辨认 | 几何与材质细节 | 战斗职责 |
| --- | --- | --- | --- |
| 迟滞者 / The Lingerer | 深灰破洞兜帽披风，开口露出红晶体身体 | 双层披风和酒灰内衬；三处真实镂空破洞及破损下摆；破口厚边、前襟缝线、背部交叉缝补；立体兜帽内壁、加厚帽沿、扣环与连接链；三枚悬挂钟摆封签 | 悬停双弹制造可预判的延迟压力，要求横向换位 |
| 锚定者 / The Anchor | 无兜帽，背部断口双环与两侧垂链 | 双层不完整光环、刻线肋条；分层肩片、胸前钟印框、交错链环和底端坠重；分裂眉架保留红色脸部 | 固定位置施放短时减速区域，改变玩家掩体选择 |
| 退缩者 / The Recluse | 深灰茧状胸壳，向两侧打开的六瓣轮廓 | 六片带倒角、棱脊、内肋和边框的分瓣护壳；铰接旋转与滑移；铆钉、固定带、短石质头罩与裂缝饰线；开壳露出红晶体胸口 | 近距离预警地面波，提供跳越、缺口和开壳输出机会 |

服饰和装甲由 `actors/enemy/sloth/sloth_visual.gd` 原创程序化生成，跟随头部和脊柱骨骼增量。布料着色器提供细织纹、折痕明暗、轻微摆动与施法亮度变化；时间由场景推进，暂停时同步冻结。破洞来自缺失几何面，不是画在布上的黑斑。静态细节按材质合并，同时保留独立骨骼跟随和壳瓣铰接。

## 当前共同规则

| 项目 | 当前原型值 / 行为 |
| --- | --- |
| 生命值 | 迟滞者 90；锚定者 140；退缩者 180 |
| 头部伤害 | 三类均为基础伤害 ×2；身体正常受伤 |
| 行动 | 迟滞者寻位／追击速度 1.8 m/s；退缩者接近速度 1.2 m/s；锚定者站定施法 |
| 施法距离 | 迟滞者 24 m；锚定者 18 m；退缩者接近到 6 m 内施法 |
| 首次准备 | 发现目标后倒计时 1.3 s；每次攻击另有可见、可听的预警 |
| 周期 | 从施法起计算冷却：迟滞者 3.6 s；锚定者 6.2 s；退缩者 5.5 s；实际间隔还受视线、距离、寻位和硬直影响 |
| 打断 | 预警阶段的有效近战击退／硬直可以取消待发攻击；击杀、撤退取消未完成攻击与领域 |
| 生命周期 | 每个敌人最多一个活动技能；领域离开、结束、取消或节点移除都清理该减速来源；暂停冻结预警与持续时间 |

### 迟滞者：Delayed Volley / 积压双弹

1. 起手时在身体两侧各生成一枚红色几何弹，预警持续 **1.0 s**；方向标线与充能音给出释放提示。
2. 两枚弹各自瞄准起手时的玩家位置，之后不追踪。每条方向单独锁定，避免玩家站在两条平行弹道之间永远不受威胁。
3. 预警后先后释放，间隔 **0.18 s**，速度 **13 m/s**，每枚 **9 BODY 伤害**。弹丸沿路径做碰撞扫掠，掩体可以挡住。
4. 悬停时击杀本体或以近战打断可阻止未释放双弹；已飞出的弹丸继续飞行。

**反制与节奏**：看清方向后横移，在悬停阶段处理目标，或借掩体换位。它保留导航寻位和增援出生寻位，不在看不见玩家的位置持续隔墙开火。

### 锚定者：Stasis Field / 沉滞领域

1. 起手时锁定玩家所在位置，显示完整外圈和向内刻齿，预警 **0.95 s**。
2. 随后激活半径 **3.2 m** 的领域，持续 **2.6 s**。领域不跟随玩家移动，不造成直接伤害。
3. 领域内步行速度为原值 **75%**，即减速 **25%**。多来源只取最强值，不相乘；冲刺的距离、速度、充能和无敌规则沿用现有实现。
4. 离开、受到实体遮挡、击杀施法者或技能结束，解除该来源的减速。站在多个领域中，移除其中一个不会错误清除其余来源。

**反制与节奏**：预警期间转点，优先击杀固定的锚定者，或保留冲刺穿过危险区域。当前没有独立可射断的锚链，也没有专属胸口弱点倍率；头部照常 ×2，击杀本体立即结束领域。

### 退缩者：Withdrawal & Recoil / 开壳拒绝波

1. 退缩者缓慢靠近，进入 **6 m** 施法距离后展开护壳；地面显示最大范围和固定安全缺口，预警 **0.95 s**。
2. 低矮波前以 **9 m/s** 向外扩散，最大半径 **7 m**；保留朝起手时玩家方向的 **44° 缺口**（半角 22°），释放后不转向。
3. 波前掠过玩家时最多结算一次 **14 BODY 伤害**，不是整个圆盘持续扣血。掩体、波外距离、安全缺口、普通跳跃与现有冲刺无敌均可用于规避；跳越判定使用脚底相对波心高于 **0.28 m** 的低波阈值。
4. 预警后段壳片已明显打开时启用胸口核心，波释放期间保持；结束后继续暴露 **1.6 s**。核心伤害 **×2**，身体始终正常受伤，闭壳不无敌。
5. 近战打断预警会取消地面波，并提供 **1.6 s** 的开壳机会；近身时要承担其他敌人交火的风险。

**反制与节奏**：用缺口贴近或普通跳越波前，在胸口暴露时集中输出；也可以全程以普通身体伤害击杀，不强制等待弱点。当前通过新增暴露核心提供收益，没有给闭壳身体额外减伤。
