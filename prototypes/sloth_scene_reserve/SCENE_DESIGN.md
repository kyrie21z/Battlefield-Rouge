## 体验与尺度

| 场景 | 核心感受 | 场地组织 |
| --- | --- | --- |
| 第一关：停滞前庭 | 进入凝固的云上建筑，先认识延迟威胁 | 开阔入口、下沉中庭、双侧高台、出口前庭；中轴可走通 |
| 第二关：锚定回廊 | 熟悉的建筑变得更受约束，利用高低与侧路转点 | 复用地形骨架，调整掩体、中央阻隔、悬浮顶棚与暖光侧庭 |
| Boss：云上静滞圣殿 | 空间豁然打开，聚焦沉眠巨像的最终舞台 | 独立圆形平台、巨环、钟摆、环形柱廊、远景悬浮殿群 |

前两关主场地各为 **96×128 米**，总面积可以大于 Boss 战斗平台；Boss 的观赏高潮来自直径 92 米的集中环形场、约 77 米高的完整巨环和向心构图。前两关采用较低的直线柱框、局部悬浮梁与分层路线，不重复完整巨环和钟摆。

## 共用地形骨架

坐标以庭院中心为原点，入口在正 Z、出口在负 Z；常规地面 Y=0。桥、缓坡和平台均有实体碰撞，主路线不要求跳跃。

| 区域 | 预演尺寸 / 高度 | 作用 |
| --- | --- | --- |
| 入口与出口前庭 | 各 96×32 米，Y=0 | 开始 / 结束一段空间节奏，提供横移和转点 |
| 中央下沉庭院 | 40×32 米，Y=-2.5 米 | 中段交战与穿越，区别于单层平板战场 |
| 中轴前后缓坡 | 各宽40米、水平长16米，连接0与-2.5米 | 主路连通，可直接走进 / 走出下沉庭 |
| 中庭左右横向缓坡 | 各宽12米的侧向开口，连接-2.5与0米 | 危险区内可向两侧撤离，避免中庭成为死坑 |
| 左侧上层廊台 | 14×64 米，Y=+3 米 | 侧翼观察、转点、俯瞰中庭 |
| 左廊前后缓坡 | 水平长18米、宽14米 | 连通入口和出口侧，不依赖跳跃 |
| 右侧上层廊台 | 14×48 米，Y=+5 米 | 更高的绕行与空间辨识 |
| 右廊前后缓坡 | 水平长30米、宽14米 | 控制爬升坡度，保留走射手感 |
| 高架横桥 | 两端连接左右廊台，宽6米，Y从3米缓升至5米 | 横跨下沉庭院，形成可见的上下层关系 |
| 入场与离场桥 | 各宽12米、长24米 | 明确方向并看见云海；端部为安全观景边界 |

复杂度主要来自 **多个可互相看见、能互相转移的高低路线**。用三段庭院、廊台、柱洞、桥下空间和遮挡切分视线，避免把新增面积做成更大的空地。边缘护栏、坡口和高差需清楚可读；下沉边缘留出明确通道。

左右上层平台的内缘位于 X=±32 米，侧向缓坡外缘在 X=±26 米，保留至少6米宽的低路绕行带。平台下方的通行净高也需覆盖站立角色高度。

## 两关的差异

第一关保留更开阔的天空和中轴，悬浮顶梁较疏，供玩家先学会识别延迟弹道。入口附近预留一段没有敌人贴脸的观察空间；常见攻击方向集中在前方，站立可用的完整掩体与矮景观构件分开。

第二关复用地形，但将掩体位置错开，在下沉庭院增加中央阻隔，给左右绕行与高架换线更多价值。高处顶棚更密，少量束缚线和静止结构强化“被锚定”的感受。出口一侧保留暖光静息庭作为视觉提案；不自动添加回血或奖励。

敌人预留点仅为 `Marker3D`，带角色建议和规划标记，不实例化敌人 AI。迟滞者、锚定者等组合用于后续评审，不表示本版已经完成遭遇战、刷怪、难度或数量平衡。矮掩体不视为站立玩家的完全遮挡；完整掩体须可实际挡住眼高射线。

## 可读性与舒适度

- 延续已修复的单层地面：结构底板低于铺装，坡面与平面只在边缘相接，避免暴露共面重叠。
- 地缝采用像素导数过滤与远距离淡出，不使用高频随机颗粒；细装饰不投射细碎阴影。
- 场景默认静止。没有自动镜头晃动、强制运镜、动态曝光或连续闪光。
- 步行碰撞与渲染帧相机插值分开，机位切换和复位即时重置；平台、坡面和高架桥都需实际角色通行验证。
- 减速区和弹道属于后续玩法。正式组合时必须保留可辨认的撤离方向，不能让中庭、高桥或中央阻隔形成必死夹击。

## 备案范围与后续接入
