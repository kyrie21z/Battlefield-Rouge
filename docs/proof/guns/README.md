# 三把枪与狙击镜（AC-05 的枪械部分）

AC-05 要求「枪 ×3、近战 ×3、自身护盾都能用，剪影可读」。这一份是枪：突击步枪、霰弹枪、狙击枪，滚轮切换；狙击枪开镜后滚轮改倍率。

截图来自临时探针（真实窗口里摆姿势拍的帧，不是录屏）。探针不留在仓库里：它只负责摆姿势拍照。

镜面改过两版才定下来：先是「圆形窗口 + 四周全黑」（同高度的圆只能用到 16:9 画面一半多宽度），再是「整帧椭圆 + 渐晕」，两次都在吃玩家瞄准用的画面。现在**不遮任何黑**：`ui/scope.gd` 只画准星、密位刻线和倍率读数，镜的身份由变焦、分划、以及 HUD 收起普通准星三件事表达。

## 模型

霰弹枪和狙击枪用的是用户给的 FBX（`tools/gun_sources/Shotgun.fbx`、`Sniper_2.fbx`，Quaternius 的 Toon Shooter 套件），不是程序化拼的：`tools/export_gun_models.py` 把它们规整成第一人称模型再导出 `assets/models/weapons/{shotgun,sniper}.glb`。

规整后的约定（和近战一致，所以 view scene 里不用补偿旋转）：

- 握点（扳机手的位置）在原点，枪口朝 Godot **-Z**，上方是 +Y；
- 长度按第一人称重定：霰弹枪 88 cm（原 155 cm），狙击枪 108 cm（原 175 cm）；
- 握点在长度的 26% 处，所以枪托留在原点后面 23 / 28 cm，摆到镜头前时会被近裁剪面切掉，不会糊住右下角。

导出脚本里有两处是**声明**而不是猜的，因为几何猜不准：

- **哪头是枪口**：泵动霰弹枪的枪托比「枪管 + 弹仓管」的前端还细，所以「窄的那头是枪口」这条会在它身上反掉。两个都写 `muzzle: max`（这套模型枪口朝 +X），脚本仍会算一遍窄头猜测并把两边半径打进日志，不一致时能看见。
- **哪边是上**：PCA 主轴的**符号**是不确定的，狙击枪的第一版就整个翻了过来（镜筒朝下、弹匣朝上），靠 `flip_up` 纠正，并由上面的侧视截图复核。数字本身判不出来，只有看图能。

## 局限

- 截图是静帧，射速、后坐、开镜过渡的手感仍要玩。
- 镜内是「真变焦 + 分划遮罩」，没有做镜筒模型的光学效果（色散、暗角渐变）。
- 换枪的弹道验证在 `tests/weapons_test.tscn` 里，用真实守卫量伤害，不靠这几张图。
