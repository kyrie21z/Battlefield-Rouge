# 黑晶手枪（#101）

单手黑晶手枪使用原创 Blender Shade Flat 模型，尺寸 220×135×32mm，120 源面／180 导出三角形。四块各有中心 pivot，根在握把中心；作者文件、几何统计及 SHA-256 在 `tools/epic1_models/`。

8 发半自动，0.18 秒间隔、35 伤害，30m 后衰减至 90m 的 50%；75°→58° ADS，1.2° pitch、±0.3° yaw，0.12 秒镜头回弹。命中喷出实体多面体晶屑。暂沿用常规计时换弹和有限储备；晶体绽放/悬浮/归位由 #102 引入。

玩家只配置一把手枪；旧多槽 API、旧近战和锤保留到相应后续迁移，不提供旧枪的玩家切换。HUD 显示弹数/容量。此阶段保留原影子身体，完整身躯感知属于 #105。

验证入口：`tests/obsidian_pistol_test.tscn`，及 gun_feel、hit_feel、HUD、原近战/锤测试。
