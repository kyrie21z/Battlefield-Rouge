# 恐惧领域：白色断裂圣殿

2026-11-15，Issue #211。基于 main `8d3db20` 的已实现版本。用户要求白色为主、紫色点缀，稍有恐怖与宏大感，但实际战场不要扩大；后续补充高空幽魂。

## 空间与观感

入口正对三重尖拱、柱廊和出口上方的巨型窥视之眼。白色石构占主要画面，深紫天空与淡雾显出断桥下的深渊；紫色只用于柱内嵌纹、桥边短线、断口和眼睛。悬墙、飞扶壁、深处残骸与断裂拱肋制造压迫感，不使用血腥贴图、突然闪屏或全屏浓雾。

宏大感来自纵向和外围：拱顶最高31米，主柱位于 x±17米，外悬墙约 x±24米。它们是可见的无碰撞景观，不生成可走的远路。原本中央翻桥和四侧岛仍为战斗主体。

| 项目 | 当前默认 |
| --- | --- |
| 玩家入口 / 出口 | `(0,0,16)` / `(0,0,-20)`，直线36米 |
| 侧岛范围 | x最外±10.5米；实际通路范围保持原尺寸 |
| 普通房新增侧台 | 两侧各3×6米，台面高1.2米，位于 x±9、z0 |
| 上下台路线 | 每台前后各4米水平缓坡，约16.7°，无需跳跃 |
| 低掩体 | 内侧高1米、厚0.28米、长3.6米 |
| 中央危险路 | 原有3块翻板及桥缝，未增加不可见障碍 |
| 坠落 | 原30点真实生命扣血、稳定平台恢复，扣至0才死亡 |
| 幽魂 | 每房固定6只，离地约6.35米以上，无碰撞、伤害或掉落 |

普通两房共享紧凑骨架。第一房柱拱相对完整；第二房右侧中排柱体缩为断柱，悬空的柱冠与缺失拱肋形成明显不对称，并有倾斜残尖塔。Boss房沿用18×11米审判台，不添加侧台或掩体；侧后方的殿壁与肋拱作仪式框景，保留Boss的战斗视线。

## 天上的幽魂

幽魂使用原创低多边形袍体、半透明淡白兜帽、暗色空面和紫色眼睛。分布在柱廊与巨眼之间，缓慢左右游移、上下浮动：横向幅度1.5米、竖向0.65米、纵向0.55米，基础相位速度0.32弧度/秒。六只共享网格和材质，只更新六个变换，暂停会冻结。

这是环境幽魂，不是新增战斗敌人：不加入敌人列表、清场计数、碰撞、导航或音频声部，不吸收玩家子弹。原敌人、Boss、掉落与随机领域顺序沿用当前主线。

## 实现边界

`FearRealm` 继续拥有桥、翻板、出生点和坠落处理，组合 `FearSanctum` 生成建筑。`chamber_style=1` 只用于 `fear_2.tscn`，由 `tools/gen_realms.py` 配置，经 `tools/gen_zones.py` 统一重建。正式领域使用现有 `set_player` 注入专用相机 Environment，避免通用 Stage 环境覆盖紫色远景。

`DistantArchitecture` 全部无物理体，不参加导航；`SideBalconies` 只包含真实侧台、坡道与低掩体，使用 WORLD 层及 `navigation_geometry`。装饰采用共享材质和尺寸缓存，不新增动态光源或粒子，新增景观网格关闭投影。桥边嵌纹高于地面约4厘米，避免共面闪烁。

所有新增运行视觉均由本项目代码与 Godot 基础网格构成，无第三方素材或旧工程素材。实机图、原生通行及回归日志见 [验证记录](../proof/fear-sanctum/README.md)。当前为可玩的场景版本；其他显卡、低端设备和真人主观恐怖程度反馈仍待收集。
