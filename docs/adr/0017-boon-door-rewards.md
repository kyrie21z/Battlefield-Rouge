# ADR 0017：门扉馈赠与构筑选卡

状态：Epic 2 / #124 实现。以 #114–#123 的资源与动作槽位为前置。

正式 ZoneDirector 的进场/插旗后 F 交互改用 BoonPicker。依旧保留两小关与 Boss、每局三次选择的原型流程；本 issue 不增加房间图、商店、局外石榴升级或持久货币。完整 54 张资源均在 BoonCatalog 登记，前置条件在抽取时检查。当前三次选择不足以让普通开局自然累积两张次级特性后再抽传奇；传奇机制由真实战斗测试验证，后续多房间循环才能提供自然成型的长度。

`tests/boon_combat_bench.tscn` 是显式调试试炼台，可直接试用四系完整构筑与六组双重组合，保留生产枪/刃/冲刺、慢弹、时钟及真实撞墙敌人；测试构筑跳过发牌前置，界面明确标注，不接入正式关卡，也不修改 RunState。

## 流程与数据

- 开局固定提供枪/刃/冲刺各一张核心，从各系中种子抽取；通关门扉先确定一个心魔，三选一候选与该徽记一致。双重共鸣可出现在其任一前置心魔的门扉，但仍要求当前装备对应的双系核心。
- 选卡 RNG 属于 ZoneDirector，独立于战斗 RNG；重复查看与重抽不消耗战斗随机序列。相同种子、相同重抽操作可复现。普通/稀有/史诗/传奇/双重的抽取权重为 6/4/2/1/1，是可明确调节的原型默认值。
- 初始重抽次数为每局 2，`RunState` 扣费，界面只发请求；重开/死亡恢复初始数，不引入局外成长。足够候选时避免重抽出原有三张；前置条件、已拥有过滤始终生效。
- 同槽位替换必须明确确认，取消保留旧卡及修饰器；选择期间暂停背景但保留入场翻转、按钮与音频。零候选显示继续按钮，防止暂停死锁。死亡界面接管暂停，不被旧选择层销毁时覆盖。
- 选择立即挂载 BoonManager，由 `loadout_changed` 经 Zone 保存到 RunState；换关只清理现场效果，不清空已选卡。历史记录保留每次接受的槽位/心魔/id，替换不伪装成叠层。

## 显示

原创 SVG 提供琥珀时钟、紫眼、红刺、蓝泪、石榴、生命和商店七种门扉标识；后三种是可供后续房间配置使用的展示组件，不声称此 Epic 已实现商店或局外经济。生产门扉使用四系真实赐福类型。双重卡显示彩色交叠晶纹与金边，所有卡给出动作槽位、稀有度、完整数值说明及替换警告。HUD 同时展示当前赐福和旧 fixture 自带的历史增益。
