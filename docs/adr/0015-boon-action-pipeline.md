# ADR 0015 — 可撤销赐福槽位与同步动作管道

状态：实现于 #114。范围是 Epic 2 的公共基础；各系效果与完整发牌 UI 分别由后续 issue 提交。

原 Buff 只有累加数值，不能安全地覆盖一个枪槽并保留其他历史增益。增加 source-key modifier 层，并让 BoonManager 独立管理四个核心槽和次级特质。替换先提出请求，确认后一次移除旧来源并装入新卡；同一 Script 只持有一个 effect 实例，避免三张同系卡重复监听一个命中。

伤害前后上下文保留真实 Hitbox、表面点、来源和衍生深度。Health 的受伤前拦截在扣血之前执行，仍尊重原队伍、弹反、无敌和反击盾顺序；新屏障通过独立吸收接口叠加。敌人和弹丸局部时间由管理器恢复，暂停及死亡有明确生命周期，不采用全局零时间导致恢复逻辑也被冻结的方案。

Zone 独占 RunState 持久化。切场景释放 effect 时不保存空装备。旧 Buff 与旧 picker 在基础变更中保留；不装备新卡时不消耗新游戏随机数，后续完整构筑采用独立 seed 流。各系池动态加载，允许逐 issue 提交而不制造临时空资源依赖。
