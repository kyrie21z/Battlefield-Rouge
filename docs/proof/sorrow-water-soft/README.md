# 涉水轻柔版

2026-11-11，Issue #209。PR #208在本次处理期间合并，因此本修订基于最新main `8d3db209f705878713999bef5766ba2862e2dd52` 单独提交；其源码树与本机对照头 `200cef1c8545caeb8b6bafbc06f6308694dd23a1` 完全相同。用户反馈原创水声仍太响，希望更温柔。

- 合成增益从0.80降至0.38，增加0.30系数的一阶平滑以收掉尖亮高频；起音45→75ms、淡出120→180ms。正式领域和独立几何fallback的涉水播放电平均从-13降至-17dB，共用音库常量。
- 步行0.60秒、冲刺约0.65秒及原距离/间隔/湿区/落地/暂停/剥夺/死亡条件保持；继续使用本项目原创合成，无参考录音采样。其余五种悲伤音色PCM逐字节不变。
- 原生sorrow_audio16、相关无界面音频集成12、水面32、雨底13项通过。实际涉水/冲刺、站立/干台、暂停、剥夺和死亡清理正常；最终四份日志无脚本/导航错误或退出诊断。没有画面变化，不新增截图或不相关玩法测试。
