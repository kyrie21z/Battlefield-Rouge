# 03 规则

声明式事实。实现细节不写在这里。来源是 [Cut-001b](../Cut-001b.md) 及其勘误。数值是已锁定的临时默认，试玩后可调，做成配置。

验收编号只有 Cut-001b 的 AC-01 至 AC-08。

作废：±120ms、把 +12% 或 +20% 当成另一套配置。+12 个百分点只是 8%×1.5 的换算，配置旋钮是倍率 1.5。

Boss 与小关共用占点配置。清零之后才能砸，只约束小关。Boss 仍是一波城市核心，胜负由 AC-02 验收。

同一起点要能再跑出一局。AC-07 不许口头通过，证明是 fixture id 或录屏路径。现有 fixture 是 FX-001（新开一局）和 FX-002（Boss 起点），做法和限制见 [ADR 0005](../adr/0005-reproducible-runs.md)。

## 解锁

解锁顺序是规则，不是 AC-01。AC-01 只验收小关两段。

1. 新局只开放小关 1。
2. 小关 1 插旗结束 → 开放小关 2。
3. 小关 2 插旗结束 → 开放 Boss。
4. Boss 插旗 → 胜利，不选增益。
5. 阵亡：流派与本局解锁清空，从第 1 关重开。

关卡选择只切换已开放的关。
