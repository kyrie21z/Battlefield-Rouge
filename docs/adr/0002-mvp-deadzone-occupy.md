# ADR 0002：MVP 改为 DR2 枪感 + 砸点占点

日期：2026-10-25　状态：已采纳

## 背景

ADR 0001 把旧工程收成可玩骨架。现在的代码仍是那条循环：清掉战区里的敌人，站在 `CapturePoint` 里把圈占满，三选一，进入下一张图。仓库里是两张图、一把突击步枪、六条通用增益。

课程是腾讯游戏学堂《AI游戏进化论》EP.04。玩法参照改为《Deadzone Rogue 2》：要它的第一人称枪感和本局构筑。和它的差别放在关卡流程。小关先清守卫，再在增援里用锤砸毁据点。

范围和验收记在 [Cut-001](../Cut-001.md)。发出后有一版草稿把窗口写成 ±120ms，把进度写成 +12% / +20%。那组数已作废。

## 决定

1. 设计目标以 [MVP_Scope.md](../MVP_Scope.md) 的 5 行和 Cut-001 的 AC-01 至 AC-07 为准。
2. 放弃战地式大规模征服，也放弃站圈读条。代码里的 `CapturePoint` 可以暂时留着，直到实现 PR 换掉它。
3. 小关过段、锤击进度、完美打击窗口锁定为临时默认：当前波次归零后才能砸；普通锤 +8%；命中时刻 ±150ms 内本次进度 ×1.5，并有专用音效和闪光；增援不回退进度；100% 插旗并冲击波。三个数做成配置。
4. 增益：进关前选 1 条；小关结束再选 1 条并本局叠加；Boss 结束后不选。池子是 3 个流派各 3 条，共 9 条。条目效果 Design-TBD。
5. 解锁顺序：小关 1 → 小关 2 → Boss。关卡选择只切换已解锁的关。
6. 本 ADR 不改玩法代码、地图和资源。`ARCHITECTURE.md` 里「一个战区的流程」仍描述当前代码。

## 后果

- 文档和可玩构建会暂时不一致。试玩旧图不能用来验收 AC-01 至 AC-07。
- 六条旧增益和单步枪不是 9 条增益、三把枪的完成态。
- 试玩后可以改 150、8、1.5 这三个配置。把 ±120、+12、+20 写回去需要新的 ADR。
- 九条增益的效果在 Design-TBD 期间不要由实现自行补倍率。
