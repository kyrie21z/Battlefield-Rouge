# 素材登记

每个进入仓库的第三方文件都要登记在这里。原始压缩包和完整下载放在仓库外的
`../third_party_sources/`（含 `SHA256SUMS`），不提交到 Git。

Quaternius 的素材包页面标注 CC0；其通用许可证 QAL v1.0（2026-08-28）禁止把素材
单独再分发，所以仓库里只放游戏实际用到的文件，不放整包。
