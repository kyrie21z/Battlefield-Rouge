# 悲伤完整池与无尽悲渊

对应 #122。完整池3核心+6次级+2高阶+1传奇，所有前置由共享BoonManager检查；高阶为OR，传奇要求2张本系特质（核心不计数）。

- 泪水回响：拾取水波对可见敌人施加1层并以4m/s击退；引力潮汐：0.85m基础拾取半径×2.5，晶体以2m/s聚拢，WORLD阻挡移动路径。
- 潮湿缓冲：默认至少20点的单次结算伤害，50%形成固定3s债务。债务不再次享受Stats减伤，不再次转化；仍通过真实Health免疫、屏障和保命管线。未结算的部分延后，实际扣血和吸收均还债，拾晶消除剩余债务。`sorrow_deferred_tick.damage` / `resolved_debt` 仅报告本次真实结算额；免疫时不发虚假的反伤事件。
- 浸润重压：满5层使真实Enemy与SlothAttack起手×1.3，新发出的敌弹时间×0.6，状态消失/装备移除撤销；深海窒息通过Health source-key阻断自然盾恢复，并使已判定暴击的最终伤害×1.4。共享Health有实际盾值、恢复、吸收入口；现有地图敌人默认0盾/0恢复，本卡不擅自添加新盾兵。
- 悲恸裂片：真实枪线或刀切击中泪晶后互斥消费，3m可见范围45基础伤害并施加2层。融蚀洪流：满层目标每次实际受伤（含DoT）向3.5m可见邻居传播1层；添加状态本身不直接造成伤害，计时DoT后续传播，不形成同步递归结算。
- 悲悯之泉：每个仍存在的泪晶提供4%承伤减免，9颗封顶36%，来源随晶体消费即更新。此卡提供持续2点/秒、上限35的过载盾自然恢复；受到伤害不重置该恢复节拍。数值为显式试玩参数。
- 无尽悲渊：真实玩家击杀留下6s涌泉；已有泪晶消费后变成追踪水刃，涌泉每0.6s再射一刃。默认水刃22m/s、14基础伤害、3s寿命，按扫掠线段穿透不同Health各一次，WORLD墙体终止飞行；最多12个同时涌泉，超额替换最老者。
- 与核心组合的修正：地面晶体发射时抬升0.35m，避免擦过生产敌人受击盒下缘；空中死亡掉落先投射到WORLD地面。模型仍为独立平面法线晶体，不添加外部素材。
- 所有暂态随暂停冻结、死亡/换场/清装移除；owner/effect相互引用在cleanup解开。音频测试曾捕获独立SlothAttack的WAV/Playback未释放，已用共享cancel先停止/清stream并走真实cancel关闭；最新日志无泄漏。
