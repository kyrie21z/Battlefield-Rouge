# #117 惊悸、实体破绽与三个恐惧核心

破绽是敌人前胸/背部的八面体 `Hitbox`，有独立凸包与真实射线接触判定。
普通惊悸破绽、爆头和背刺采用 200% 倍率，枪直接击中晶面采用 260%，
替代原有部位倍率，不再重复乘爆头 2.5。枪碎面后移到背部；其他命中消耗该面。

- `gaze_pierce.tres`：4 秒惊悸，首次普通命中不会提前暴击。
- `flash_backstab.tres`：Stats 刀速 ×1.3；原被弹反飞弹保留扫掠碰撞，
  转成紫晶并追踪最近破绽，真实撞中敌人才引爆全部当前破绽，每面基础伤害 35。
  墙壁会阻断飞弹。爆炸使用快照并带 `proc_depth=1`。
- `tremor_decoy.tres`：1 HP 实体残影，2 秒超时或敌弹击破只爆发一次；
  默认吸引可见 16 米内敌人，爆发向可见 6 米内附加 4 秒惊悸，恢复先前仇恨目标。
  复用主角现有晶体人体，冻结冲刺瞬间的 24 骨局部姿势与朝向；完整显示头部、手臂与双腿。
  每个残影独享紫色半透明、微反光材质，模型轻微抖动，不运行主角动画或修改原材质。
  缺少姿势来源时冻结原模型的 `idle` 姿势。

晶面、紫色暴击飘字和水晶声均为代码生成；残影复用仓库内现有主角模型。
声音为固定正弦泛音衰减，不消费玩法随机数，未引入外部素材。
紫色只用于恐惧技能，未修改主角黑色接缝或原 GLB。

验证入口：`tests/fear_boon_core_test.tscn` 覆盖实际 Health 数值、晶面空间判断、
部位倍率替换、残影受伤/超时/仇恨恢复、真实反射弹命中与跨敌引爆、暂停及清理。
`tests/fear_boon_proof.tscn` 用生产迟滞者模型展示前胸、背部晶面与残影。
Godot 4.7.2、`--headless --fixed-fps 60`：18 项行为检查通过，无脚本错误、警告或资源泄漏；
见 `core-test.log`。原生 Forward+ / RTX 4060 生成并人工查看 `fear-core.png`，
确认前胸、后背晶面均显露、残影保持完整人体轮廓且标签清楚。背面偏移为 0.44 米。
`tests/fear_decoy_snapshot_test.tscn` 的 15 项检查通过，覆盖 24 骨逐项姿势、朝向、完整身体、
动画冻结与独立材质、原主角材质不变、抖动、暂停、真实 Hitbox 受击和两秒到期；
见 `snapshot-test.log`。更新残影后同时重跑 18 项核心与 39 项特质回归。
静态取证不代替完整战区的人工手感验收。
