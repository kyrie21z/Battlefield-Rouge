# 功能优先级

> 腾讯游戏学堂《AI游戏进化论》EP.04。范围以 [MVP_Scope.md](MVP_Scope.md) 的 5 行为准。验收编号以 [Cut-001b](Cut-001b.md) 的 AC-01 至 AC-08 为准。勘误：窗口 ±150ms，普通锤 +8%，完美 ×1.5。作废 ±120ms、+12%、+20%。

## 优先级

| 级 | 含义 |
| --- | --- |
| P0 | 不做就不是这个游戏 |
| P1 | 做了，核心乐趣才完整 |
| P2 | 更耐玩 |
| P3 | 更「高级」，删了不影响核心 |
| 待拍板 | 不是优先级。规则或效果还没定，不许用猜测数字开工 |
| 砍掉 | 不排期 |

P0 对应该打通的行为，包括 Cut-001b 已经锁定的临时默认。那些数做成配置。P1 是 AC 通过之后仍要打磨的手感，不是另一套验收编号。

## 清单

| 功能名 | 优先级 | 一句话理由 |
| --- | --- | --- |
| 小关两段 | P0 | AC-01：清守卫 → 占点 → 插旗可玩。证明是 60 秒视频或状态机截图。 |
| 清守卫 | P0 | 小关当前波次归零后，锤击才加占点进度，这是 AC-01 的第一段。 |
| 锤砸占点 | P0 | AC-01 的占点段。普通锤 +8% 写在 AC-03 的配置里。 |
| 插旗 | P0 | AC-01 的收束：100% 插上己方旗。冲击波距离仍待定。 |
| 冲击波推开 | P0 | 插旗时推开剩余敌人。米数未定，不在这里补。 |
| 增援不回退进度 | P0 | 增援只造成生命压力，不减少占点进度。 |
| Boss 一波城市核心 | P0 | AC-02：只有一波，打城市核心，要能分出胜利或失败。 |
| 完美打击 | P0 | AC-03：±150ms 内本次进度 ×1.5，并有专用音效和闪光；窗口外反馈不同。 |
| 完美打击配置核对 | P0 | AC-03 的证明是调试条，加上配置所在路径。不先编一个还不存在的文件名。 |
| 进关选择增益 | P0 | AC-04：每一关开始前选 1 条，含第 1 关和 Boss。 |
| 小关结束再选增益 | P0 | AC-04：两小关打完各再选 1 条，和进关那次分开，本局叠加。 |
| Boss 结束不选增益 | P0 | AC-04：Boss 没有下一关，插旗后直接胜利。 |
| 九条增益 | P0 | AC-04 的池子是 9 条可叠加。效果 Design-TBD，不另做连携或进化。 |
| 三把枪 | P0 | AC-05：步枪、狙击枪、霰弹枪都能用，剪影可读。伤害和弹匣未定。**2026-10-26 已能玩**（滚轮切换，证明见 `docs/proof/guns/`），数字仍是试玩默认值 |
| 三把近战 | P0 | AC-05：匕首快/近/低，斧慢/中/高，太刀中/远/中。数字未定。**2026-10-26 已能玩**（V 挥砍、Q 切换，证明见 `docs/proof/melee/`），数字仍是试玩默认值 |
| 一秒护盾 | P0 | AC-05：自身护盾可用，无敌 1 秒。按键和冷却未定。 |
| 三派图标可读 | P0 | AC-06：三个流派的图标和效果能看懂。效果数值仍 Design-TBD。 |
| 同起点复现 | P0 | AC-07：同一起点能再跑出一局。证明是 fixture id 或录屏路径，不许口头通过。 |
| 每派三条图标 | P0 | AC-08：每派至少 3 条能被选中，图标不同。证明是选择界面截图。 |
| 线性三关 | P0 | 内容就是两小关加一个 Boss。 |
| 关卡选择 | P0 | 只切换已解锁的关，顺序是小关 1、小关 2、Boss。这是规则，不是 AC-01。 |
| 阵亡重开 | P0 | 生命归零则增益和本局解锁清空，从第 1 关再开，保证 AC-07 的同一起点。 |
| 胜利结算 | P0 | AC-02：Boss 插旗即胜利，并提供重开。 |
| 三枪手感 | P1 | AC-05 只要求能用、剪影可读。射速和后坐仍要实机打磨，数字未定。 |
| 三近战手感 | P1 | AC-05 锁定的是快/近/低这三档定性。距离和伤害数字未定。 |
| 插旗手感 | P1 | AC-01 要有插旗。这一行要求分量够。 |
| 增援压力 | P1 | 占点时增援要让人掉血。进度条本身不被它倒扣。 |
| 现成据点建筑 | P1 | 灰盒可以测砸击。换成许可清楚的现成模型。定制美术砍掉。 |
| 增益效果文案 | 待拍板 | 九条的占位名可以改，效果没有倍率，见 03_rules。AC-06 不因此放行填数。 |
| 枪械与近战数值 | 待拍板 | 定性已锁定，伤害、射速、距离都没有默认值。 |
| 冲击波距离 | 待拍板 | 只要求推开剩余敌人，不写米数。 |
| 分支路线 | P2 | 线性三关已经能验证循环。 |
| 每关独立身份 | P2 | 关卡各自的空间身份放到循环被玩懂之后。 |
| 更多关卡 | P2 | 三关打完即一局。 |
| 更多枪械和词条 | P2 | 9 条和三把枪稳定之前不加池子。 |
| 更多敌人种类 | P2 | 现有守卫和增援够把两段跑通。 |
| 故事文案 | P3 | 城市推进只是比喻。 |
| 战役宣传图 | P3 | 多线全景可以帮助讲解，原型不需要。 |
| 阵营角色叙事 | P3 | 不影响枪、锤和选择。 |
| 战地式征服 | 砍掉 | 和单人两段占点冲突。 |
| 多人合作 | 砍掉 | 验收对象是单人一局。 |
| 站圈占点 | 砍掉 | 旧的站圈读条不再排期。 |
| 全图高保真破坏 | 砍掉 | 只砸据点建筑。 |
| 清完再选卡 | 砍掉 | 拿掉占点段，设计核就没了。 |
| 定制据点建筑 | 砍掉 | 要换外观只用现成素材。 |
| 增益连携或进化 | 砍掉 | 9 条只叠加，不做第二套养成。 |
| 局外商店和永久养成 | 砍掉 | 增益只活在本局。 |
| ±120 / +12 / +20 草稿 | 砍掉 | Cut-001b 勘误已作废这组数，不能写回配置。 |
| 口头软通过 | 砍掉 | AC-07 明确不许。 |

## Scope Gate

| 层级 | 功能 / 内容 | 保留理由 | 验证目标 | 不做的代价 |
| --- | --- | --- | --- | --- |
| MVP必须有 | AC-01 至 AC-08 | 没有这些就不是这条循环 | 按 Cut-001b 的证明交视频、调试条、配置路径、截图或 fixture | 退回站圈，或退回只在关底三选一 |
| Vertical Slice应该有 | 三枪手感；三近战手感；插旗手感；增援压力；现成据点建筑 | AC 通过之后才值得再开一局 | 口头能感到差别。不新增数字 | 切片不能只剩剪影 |
| Demo后再做 | 分支路线；每关独立身份；更多关卡；更多枪械和词条；更多敌人种类 | 依赖循环已经被玩懂 | 现在不验证 | 关卡选择会膨胀成地图 |
| 宣传概念暂不开发 | 故事文案；战役宣传图；阵营角色叙事 | 帮助讲「往城里推进」 | 口头讲得清即可 | 做成可玩大地图就会滑向战地 |
| 建议砍掉 | 战地式征服；多人；站圈；全图破坏；清完再选卡；定制建筑；连携进化；局外养成；±120/+12/+20；口头软通过 | 和 Cut-001b 冲突，或是已作废草稿 | 不验证 | 范围失控，或把勘误写回去 |
