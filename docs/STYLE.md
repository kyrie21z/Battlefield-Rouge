# 风格板

垂直切片的外观锁。素材包清单在 `docs/ASSETS.md`。本文只负责颜色和可读性。

## 观感锁

Low-poly / Toon（Godot 4.7.2）。写实军事风和体素风不进入垂直切片。

角色、武器、掩体和城市模块来自 [ASSETS.md](ASSETS.md) 的 primary 包：Quaternius 的 Toon 套件，以及 Kenney。包名、许可证和已入库文件不在这里重复。

## 色板

每色一个 hex，一个用途。色按卡通平涂来选：主色在少阶明暗下仍能分开；暗色只加深同一色族，给剪影和 UI。剪影填色用暗色。

描边和卡通暗部用下表的墨线色。Godot toon 不用纯黑 `#000000`。

| 名称 | Hex | 用途 |
| --- | --- | --- |
| 狂战士主色 | `#E0242A` | 狂战士（Berserker）主强调：图标、UI 色条、武器点缀 |
| 狂战士暗色 | `#6E1218` | 斧头剪影、图标暗边、该派卡通暗阶 |
| 军火大亨主色 | `#F5C400` | 军火大亨（Arms Dealer）主强调：图标、UI 色条、武器点缀。偏黄，保持高明度 |
| 军火大亨暗色 | `#8A6800` | 弹药剪影、图标暗边、该派卡通暗阶 |
| 鹰眼主色 | `#14C8D4` | 鹰眼（Hawkeye）主强调：图标、UI 色条、武器点缀 |
| 鹰眼暗色 | `#0A6670` | 准星剪影、图标暗边、该派卡通暗阶 |
| 完美打击成功 | `#F7F8FA` | 近白短闪。成功用这一色 |
| 完美打击失败 | 不用 `#F7F8FA` | 失败不用近白闪。已有的分开反馈保留 |
| 卡通底色 | `#C9BBA8` | 未染色表面、灰盒替身。不代表流派 |
| 描边 / 卡通暗部 | `#1A1C22` | Godot toon 的描边或投影墨线，把剪影从底色上分开 |
| UI 底板 | `#1E2430` | 中性面板。三派主色放在上面 |
| UI 文字 | `#E7EAEF` | 常驻文字和图标线。不是成功闪光 |

成功和失败的反馈必须分开，规则在 [Cut-001b](Cut-001b.md)。本文只锁近白：成功用 `#F7F8FA`。失败不用近白闪，已有的分开反馈保留。

## 剪影

三派图标在小尺寸下先靠剪影认出，颜色是第二层。和 [ASSETS.md](ASSETS.md) 的可读性表同一套读法。效果数值仍 Design-TBD。

| 流派 | 剪影 | 色族 |
| --- | --- | --- |
| 狂战士（Berserker） | 斧头 | 红：`#E0242A` / `#6E1218` |
| 军火大亨（Arms Dealer） | 弹药 | 黄 / 金：`#F5C400` / `#8A6800` |
| 鹰眼（Hawkeye） | 准星 | 青（cyan）：`#14C8D4` / `#0A6670` |

- 斧头：宽刃加短柄。侧影能看出斧。
- 弹药：弹壳、弹匣或一叠子弹。金色已经表示这一派，剪影本身是弹药。
- 准星：十字或缺口环。
