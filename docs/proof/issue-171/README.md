# #171 白色空间接触阴影与 ADS 对焦

`environments/default_env.tres` 是独立复制的白色空间配置：SSAO 半径1.25米、强度1.1、SSIL半径3.5米、强度0.65；Forward+质量为 High。关卡、怠惰旧建筑、悲伤、愤怒、开场和终局仍保留各自天空/色调/光源，只共用接触阴影与间接光配置。资源逐实例duplicate，不跨房污染。

`Player/ADSFocus` 只控制实际渲染子相机的 `CameraAttributesPractical`，不写逻辑相机、弹道、移动或全局时间。ADS时每0.05秒向逻辑准星射线测 WORLD/HITBOXES，排除玩家自身；焦距指数收敛，目标附近保留清晰带，前后景轻度散焦（最大amount=0.05）。松开ADS后淡出，死亡/禁用角色进入演出立即关闭。

## 验证

- Godot4.7.2 导入无script/shader错误。
- `ads_focus_test.tscn`：11项通过，0失败，无引擎错误。检查实际物理墙面距离、真实头骨眼位、焦点收敛、近远清晰带、射线频率、退出ADS、死亡/演出禁用，以及环境资源隔离。
- 原生 `ads_focus_bench.tscn` 用正式怠惰第一房/生产Player，输出正常观察和ADS两张截图。只冻结演员AI进行可比截图，不是人工手感验收。
- 第一版测试假设眼位位于世界z=0而产生2个失败；修正为从实际头骨眼位计算已知墙平面距离（实际9.3976889米）后通过，没有改测距代码来迎合错误测试。

## 边界

SSAO/SSIL/DOF面向Forward+；Compatibility并不提供同等屏幕空间效果。截图体现目标清晰及温和景深，仍需人工动态舒适度验收。光照不是新增玩法状态，fixture物理随机与逻辑相机不受影响。

全部为原创代码和引擎内置效果，没有外部素材。#169的镜潭相机环境override在集成时继续复制同一个default_env后保留SSR和悲伤氛围。
