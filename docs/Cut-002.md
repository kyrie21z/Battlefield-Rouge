# Cut-002：Sloth 叙事闭环

日期：2026-11-02（美东）　状态：草案，待 Kyrie 确认后锁定

## 为什么有这一份

玩法循环（清守卫 → 锤砸 → 插旗 → 选增益 → 下一关 → Boss）已经能玩，接下来把游戏适配到故事背景 [Mind-Freak](https://github.com/kyrie21z/Mind-Freak)。背景的权威来源是那边的 `docs/CREATIVE_VISION.md`、`docs/WEAPON_ART_DIRECTION.md`、`docs/levels/SLOTH_LEVEL_DESIGN.md`（下文简称愿景、武器美术、LDD）。本文只决定**本仓库这一轮做什么、怎么验收**，不复述背景。

本轮目标对应 LDD 第 9 节的「战斗—胜利—失去—发现」闭环：现有三关成为 Sloth 第一层，玩家打赢沉眠巨像后，亲眼看到自己用过的休憩区熄灭，拿到 Rest Fragment，并由皇冠 Pride 真诚地给出「效率」解读。

决定（Kyrie，2026-11-02）：

1. **保留锤砸据点，换叙事外壳。** 据点是「停摆的钟」，锤按节拍把它敲醒，插旗变成钟摆重新摆动。规则、配置和 AC-03 不变。
2. **叙事闭环优先。** 沿用现有敌人和 Boss 的战斗机制，本轮不做迟滞者、锚定者、退缩者和巨像技能。
3. **设计以本仓库为准。** Mind-Freak 是背景来源；本仓库的范围和验收写在本文，取舍写 ADR。

## 与 Cut-001b 的关系

Cut-001b 的玩法规则和 AC-01 到 AC-08 **继续有效**，下面三处除外：

| Cut-001b 原文 | 本文改为 |
| --- | --- |
| OUT：故事打磨 | IN：本文列出的叙事闭环 |
| Boss 目标是「城市核心」 | Boss 关的核心是「巨像胸口的停摆之钟」，规则不变（Boss 倒下才开放，一锤到 100%） |
| Boss 插旗 1.4 秒后直接胜利 | Boss 插旗后进入战后段（见下），拾取 Rest Fragment 后才弹胜利界面 |

增益照常保留，但不是本轮重点；本轮不改九张卡。

## IN

按 PR 拆，一个 PR 一件事，顺序即建议顺序。

### P1 Pride 字幕

- 新增字幕组件：屏幕下方一行，左侧一个简单皇冠图形，显示 Pride 的台词。
- 由事件触发，台词数据放在一个 `.tres`（或同类数据文件）里，试玩只改数据。
- 不暂停、不拦截输入，不打断射击和移动；可跳过（新台词顶掉旧台词，或按键关闭）。
- 至少这几个时刻有台词：进入第 1 关、第一次清完守卫、第一次完美打击、进入 Rest Zone、Boss 关开场、Boss 倒下、战后钟摆加速、拾取 Rest Fragment。台词用 LDD 的候选句或同等口吻：真诚、有用、以效率衡量休息。
- 死亡重开后，只在一局里第一次触发的台词不重复刷屏（每局各一次）。

### P2 停摆之钟

- 据点外观换成「停住的钟 / 巨环」：开放前静止，锤击时轻微颤动，插旗时钟摆开始摆动（替代或并存于旗杆，旗的节点名可留）。
- 目标文案改为叙事措辞，例如「敲醒停摆之钟，按 E」。`Events`、阶段、配置不变。
- 节拍条和完美打击反馈不变（AC-03）。

### P3 Rest Zone

- 新组件：地面温暖琥珀色光圈。玩家在区内、且 `rest_delay` 秒内没有受伤，就以 `rest_rate` 每秒恢复生命，直到上限；受伤或离开中断。
- 原型参数（写在配置里，试玩可改）：`rest_delay` 2.5 秒、`rest_rate` 10/秒、每处每关累计最多恢复 50。
- 有三种状态：亮（可用）、使用中（脉冲）、熄灭（不可用，交互失效）。
- 不鼓励无限拖延：有累计上限，用完变暗。
- `Health` 需要一个加血入口（现在只有扣血）；加在 `components/health.gd`，只由 Rest Zone / Fragment 调用。

### P4 战后段与 Rest Fragment

- `ZoneDirector` 在 Boss 关增加阶段 `AFTERMATH`：Boss 核心插旗后进入，不再 1.4 秒后直接胜利。
- 进入时由事件驱动（不写进 Boss 脚本）：
  1. 钟摆和悬浮块从慢到快，环境音从稀疏到密集；
  2. 场内 Rest Zone 依次熄灭，玩家走进去没有恢复反馈；
  3. Boss 原位出现金色几何碎片 Rest Fragment，目标文案指向它；
  4. 玩家有一段自由观察时间，不掉血、不刷敌。
- 走近按 F 拾取：获得 Rest Fragment 能力（`rest_delay` 秒未受伤后缓慢回血，有上限），有柔和脉冲反馈，Pride 说出拾取台词，然后弹出胜利界面。
- Rest Fragment 走现有增益通道（一张不进卡袋、不进三选一的特殊 `Buff`，只改 `Stats`），死亡清空。本轮它只在本局生效。
- 战后段的规则写一篇 ADR。

### P5 白模观感

- 地图、掩体、据点改成浅灰白哑光块面 + 深色边线或明暗分隔；保证地面、掩体、敌人、可通行边缘能分开（LDD 2.2）。
- 敌人模型先用统一的浅色覆盖材质，保留剪影；Boss 换成蜷缩人形的几何近似（大块体组合即可）。
- 暖琥珀色只给 Rest Zone 和 Rest Fragment；危险提示另用一个高对比色。
- 改写 `STYLE.md` 的观感锁与色板；`TODO.md` 里 Toon / Kenney 替换条目删除或标为作废。
- 第一人称武器本轮不换（武器美术的最小验证另开一轮）。

## OUT

- 迟滞者、锚定者、退缩者；巨像的技能和两阶段（LDD P0 的战斗部分，下一轮）。
- 第二层及以后、Pride 最终战与和解。
- 配音、过场镜头、长对白、强制停留的剧情演出。
- 跨局保留 Rest Fragment、局外成长。
- 重做九张增益或改占点三个数。
- 抽象武器重建模。
