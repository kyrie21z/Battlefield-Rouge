# ADR 0010：危险弹匣打空即获得，保留 C 投掷与 6 米爆炸

- 日期：2026-11-04
- 关联：Issue [#87](https://github.com/kyrie21z/Battlefield-Rouge/issues/87)
- 状态：本次实现，等待 PR 审查与合并
- 背景：玩家反馈危险弹匣获取太晚、范围偏小且爆炸效果不显著。用户明确要求打空后立即获得一枚弹匣，继续按 C 投掷，无需等待换弹完成；最终爆炸半径取 6 米。此前方案与数值调整保留在 [ADR 0008](0008-held-magazine-and-shield-radius.md)。

## 决定

危险弹匣的获取改到最后一发耗尽时。`CombatTraits` 监听 `Weapon.fired`：成功射击扣除最后一发、`ammo == 0`，且增益已解锁、玩家存活、库存未满时，在同一帧储存一枚。三把枪共用这一条路径，霰弹枪每次射击只发放一次，不随每颗弹丸重复；无备用弹也能获得，不等待换弹完成。

库存上限一枚，已有弹匣时再次打空不叠加或替换。空仓扣扳机、手动空仓换弹、取消或完成换弹、切回空枪不会额外发放。持有不限时、不启动引信，切枪保留库存，开狙击镜时只隐藏手持模型；死亡、重开或换关清空临时持有状态，不写入 RunState。

保留 `throw_magazine`（默认 C）主动投掷，实际输入仅在鼠标已捕获时受理；暂停、死亡、未解锁或空库存时拒绝投掷。投出时读取当前 Stats 伤害，并先消耗库存再创建飞行弹匣；速度 24 米/秒、上抛 3、重力 9，投出后计 1.5 秒引信。沿用 main 的半径 0.5 米球形近敌扫掠，离敌人 0.5 米内、碰墙或地面提前引爆；同一枚只爆炸一次。

试玩默认半径从 main 的 5 米调至 6 米，保留此前的 1.5 米全伤区。每层 1.5 米内 120 BODY 伤害，向 6 米边缘线性衰减到 60；不额外叠乘枪伤倍率，无自伤或同队伤害。WORLD 遮挡与同一 Health 只结算最高一次伤害的规则继续生效。卡片仍提供每层枪伤 ×1.20；两层爆炸中心为 240、边缘 120。

投出的弹匣引爆时，使用橙色火光、双面开放波前、上下厚环、火花、烟与爆炸声；世界特效对应实际 6 米范围，从波前内外都可见。特效随暂停冻结、短暂播放后回收，中心瞄准区域保持可读，不引入外部素材或消耗玩法全局随机数。护盾继续使用独立的 7 米范围与每层均匀 25 点伤害。

## HUD 与兼容

保留原 C 弹匣方槽、手持模型和投掷按键设置：未解锁时锁定；解锁但未持有时暗态 `0/1`，最后一发打空获得后立即亮起为 `1/1`，投出后回到 `0/1`。HUD 只读取 `CombatTraits.has_reload_charge()` 等状态，不修改库存。

卡片说明、当前九增益、术语表、架构与操作说明同步此规则；历史 ADR 与 proof 保留当时事实，不倒写为本次结果。卡片构筑、三次选卡、死亡重开和 fixture 起点语义沿用既有流程。

## 验证与限制

本次 PR 的功能回归与 Godot 4.7.2 原生截图汇总在 [空仓即得弹匣证明](../proof/empty-magazine/README.md)。验证应覆盖三枪最后一发同帧获得一枚、无备用弹、库存上限、换弹与切枪不额外发放、C 仅消耗一枚、投掷时读取叠层伤害、6 米边缘与越界、掩体遮挡、Health 去重以及暂停和死亡边界。

6 米和 120→60 是本次试玩默认，仍需人工难度平衡；不据此宣称已完成长期平衡或调整其他敌人、护盾规则。
