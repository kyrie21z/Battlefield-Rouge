# 怠惰完整赐福池

对应 #116，沿用 #115 生产管线与琥珀时钟。完整池为3核心、6次级、2高阶、1传奇，每张卡只有一个稳定 ID；所有参数在对应 `.tres` 中。

- 惯性只把实际扣血蓄压乘1.5，不重复放大固定60和每枪25。共振半径×1.6；一波杀死多个目标只回弹一次，回弹深度2且不再生成回弹，不反馈进任何时钟。
- 静定的1.2s由实际三维位置变化计时，移动/冲刺立即清除；source-key Stats 同时实现0.6承伤与2.0重组速度（进行中的重组也响应）。左侧琥珀静定提示随来源显示。
- 从容装填只监听空匣重组，实际扣血使本轮奖励失效；补弹时加35过载屏障，战术重组不发放。屏障走共享Health吸收链。
- 沉重节拍每1.5s准备一次，按下一次成功枪击/挥刀动作消费，命中形成0.3移速的深度滞后。睡意给状态敌人新发出的飞弹独立0.5时间来源。
- 深度沉沦的+0.25与统一暴击概率相加，只作一次随机抽签；已有明确暴击不重复乘。爆发在同一可见半径内使幸存者昏睡1s。
- 高阶依赖为OR。时滞场域接受冲刺或任一次级特质；两活跃时钟时给所有敌人/敌弹0.8时间来源和1.5冲刺充能，低于阈值移除。新生实体也立即继承。
- 永恒停滞要求2张怠惰特质（核心槽不计数）。滞后爆发杀死Boss或标记 `elite` 的敌人，或玩家在滑动3秒窗口内击杀3敌人，冻结2s；冷调消色覆盖和低频晶鸣提示状态。敌人/飞弹局部时间为0，玩家与管理器照常推进恢复计时，`Engine.time_scale` 保持1。移除传奇、死亡、换场清除所有来源。
- 本阶段已有精英身份为 `Enemy.is_boss`，也接受生产刷怪方配置的 `elite` 元数据；不从模型大小或名称猜测。
