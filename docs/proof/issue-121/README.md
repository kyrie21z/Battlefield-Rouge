# 悲伤三核心、溶蚀与泪晶

对应 #121，采用生产 Weapon / MeleeWeapon / PlayerDash 与共享 Health 事件；`objects/tear_crystal.tscn` 是拥有真实 Hitbox 的世界实体。

- 命中后新增1层，最多5层；每次命中刷新5s持续时间。每0.5s结算每层4点基础水蚀，所有已存在层数令实际受伤增加10%/层。第一击不追溯加深，DoT同样受到加深。步长累积保证跨帧一致。
- 首次到达5层产生1颗泪晶；已经满层的后续命中不无限生成。溶蚀目标死亡另外产生1颗；死亡事件使用共享实际伤害来源。`sorrow_tear_spawn_before` 允许双赐福在同一次生成中修改数量。
- 接触拾取一次性回复25过载护盾，并产生3m半径、10基础伤害的水波；现有免疫、护盾吸收和同队过滤均保留。拾取与刀击通过 `consume()` 互斥，不能同时领奖并发射。
- 刀生效帧清除4.5m前方80°扇形的可见敌弹，并给扇形敌人加1层。斩过地面泪晶后向前发射3颗24m/s、18伤害的苍蓝晶体。原弹幕后方和墙后目标不参与。
- 水带沿实际冲刺路径以不大于0.65m的间距采样，默认半径1.15m、持续3s；交叠区域只按每个敌人累计一次0.5s，不重复叠层。站在水中玩家移速×1.3，敌人×0.6；离开或水消失即撤销来源。
- 原文未给定的DoT基础伤害、拾取水波半径/伤害、晶体散射伤害/速度与水带半径是显式 `.tres` 参数。所有范围均走WORLD视线校验，不跨墙吸附或攻击同队。
- 暂停停止状态计时；死亡、换场或清除装备移除状态、泪晶、视觉与来源修正。已释放的实体在强类型访问前清理，覆盖连续创建/拾取/刀击后的下一帧。

验证：Godot4.7.2 Windows headless，`tests/sorrow_boon_core_test.tscn`，26项全部通过，零错误/警告。日志 `sorrow-core.log`。原生渲染截图 `erosion-tears.png` 展示生产迟滞者、5层晶刺、独立泪晶与苍蓝水带。
