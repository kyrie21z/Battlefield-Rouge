# MVP 范围（腾讯游戏学堂《AI游戏进化论》EP.04）

> 2026-11-03：本文是早期 Battlefield Rouge 原型的规则，描述当前代码的行为，改动现有系统时仍以它为依据。游戏方向以 [Creative Vision](CREATIVE_VISION.md) 为准，冲突时以愿景为准；新的玩法范围按轮次写在 Cut 文档里（当前是 [Cut-002](Cut-002.md)）。

做：Godot 4.7.2 第一人称射击肉鸽。枪感与本局构筑靠拢《Deadzone Rogue 2》。线性三关（两小关 + 一个 Boss），解锁顺序见 [Cut-001b](Cut-001b.md)：小关 1 → 小关 2 → Boss。
做：AC-01 小关两段可玩，清守卫 → 占点 → 插旗。当前波次清到 0 再砸，增援不回退进度，100% 插旗并冲击波。AC-02 Boss 只有一波城市核心，要能分出胜负。
做：AC-03 完美打击的成功和失败反馈分开。窗口和倍率来自配置：±150ms、普通锤 +8%、完美 ×1.5。证明是调试条和配置路径。这三个数是临时默认，试玩后可调。勘误：作废 ±120ms、+12%、+20%。
做：AC-04 从 9 条可叠加增益里选，进关前 1 条，小关结束再 1 条，Boss 后不选。效果 Design-TBD。AC-05 枪 ×3、近战 ×3、自身护盾可用且剪影可读。AC-06 三派图标和效果可读。AC-08 每派至少 3 条，图标彼此不同。
不做：战地式大规模征服，多人/合作，分支大地图，故事打磨，据点建筑定制美术，超出这 9 条的池子，增益连携或进化，占点之外的高保真可破坏，站圈读条，以及拆掉两段占点。AC-07 要求同一起点可复现，证明是 fixture id 或录屏路径，不许口头通过。规则正文在 [03_rules.md](bible/03_rules.md)。
