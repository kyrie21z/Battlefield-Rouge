# ADR 0013：持续蓄伤反击盾与主动敌群

- 日期：2026-11-08
- 状态：已实现，继续在草稿PR #98试玩/评审

## 用户反馈与决定

反击盾原本仍套用普通盾的2秒寿命，只记是否挡过攻击，到期固定25伤/层；用户要求护盾一直存在到累计伤害破盾，满盾自动反击，未满可手动释放。用户同时要求每关初始敌人数约乘1.8，敌人进攻更主动。

反击卡按G开启后改为持续容量盾，默认100点、无计时消失。满容量自动释放，再次G可提前释放；伤害为实际吸收量×反击卡层数，沿用7米、有墙体遮挡的均匀BODY反击波。空盾可收起但不制造伤害。释放后冷却8秒，能量回流仍乘冷却、最低0.5秒，冷却结束按G重新开启。

容量按身体部位倍率后的实际来袭伤害计算；破盾一击超出剩余容量的部分正常扣血。友伤、弹反、冲刺与外部无敌先过滤，不给护盾白充能。死亡/换关取消盾和未释放反击，致命溢出不死后反击。普通技能盾仍为2秒保护/8秒冷却；持久屏障保留普通盾+0.5秒，并新增容量+25，使其在反击模式也有收益。反击卡原+15最大生命保留。

## 组件契约

- `Health.damage_absorber: Callable`在友伤/其他保护过滤及部位倍率后消耗伤害，返回未吸收部分；Health仍负责HP和死亡。
- `Health.damage_resolved`在最外层伤害全部结算后发送。深度计数在调用吸收hook之前递增，避免`absorbed_hit`回调嵌套伤害提前消费自动反击。
- `PlayerShield`持有容量/吸收/激活状态，`counter_released(absorbed)`交给CombatTraits结算波。`is_active()`供UI判断保护，不把容量模式塞进`active_remaining`或无限大计时器。状态先消费再发信号，重复释放不复制反击。
- G槽显示吸收/容量与进度弧；生命上方紫条显示剩余容量；屏幕盾缘一直保留到释放。普通盾仍显示倒计时。

## 敌人压力

按四舍五入，三关初始Sloth小怪4/6/6→**7/11/11**；Boss本体仍1。增援仍每10秒2名、最多5名，场地和22/24米据点距离保持。

`SlothEnemy.setup`在正式开战绑定目标后主动搜敌，不等玩家先开枪；初始施法延迟按0.25/0.40/0.55/0.70秒错开。跑速迟滞/锚定/退缩为2.8/2.1/2.4米每秒；锚定者失去射程或视线时也会追近。实际有视线和射程时可认领当前位置及时施法，保留共享射位3.5米间距。锚定/退缩施法周期改4.4/3.6秒，迟滞3.6秒不变；四连弹2秒蓄力、最后0.45秒锁向、完整1秒恢复和伤害不变。

新增掩体与出生点保持真实胶囊不重叠、同层导航/掩体可用、直达路线畅通，Boss仍有两名近卫。机制加强和更高密度共同作为本轮战斗试玩修订，真人难度仍待反馈。

## 验证

28项容量盾检查覆盖长期激活、手动35/满100、溢出、致命、部位倍率、友伤/其他保护、暂停、重入与嵌套致命结算。主动性测试验证锚定者先绕满高掩体取得实际视线才施法；整局观察不强制alert，7/11/11均实际移动或施法。最终全部测试、真实G原生取证、完整流程与fixture证据见[当前证明](../proof/counter-pressure/README.md)。旧盾/低密度取证保留为历史。
