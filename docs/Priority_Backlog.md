# 功能优先级

> 腾讯游戏学堂《AI游戏进化论》EP.04。范围以 [MVP_Scope.md](MVP_Scope.md) 的 5 行为准。验收编号以 [Cut-001](Cut-001.md) 为准，含 2026-10-25 勘误：窗口 ±150ms，普通锤 +8%，完美 ×1.5。作废 ±120ms、+12%、+20%。

## 优先级

| 级 | 含义 |
| --- | --- |
| P0 | 不做就不是这个游戏 |
| P1 | 做了，核心乐趣才完整 |
| P2 | 更耐玩 |
| P3 | 更「高级」，删了不影响核心 |
| 待拍板 | 不是优先级。规则或效果还没定，不许用猜测数字开工 |
| 砍掉 | 不排期 |

P0 对应该打通的行为，包括 Cut-001 已经锁定的临时默认。那些数做成配置。P1 对「还想再玩」所需要的可读手感，不是出货级美术。

## Scope Gate

| 层级 | 功能 / 内容 | 保留理由 | 验证目标 | 不做的代价 |
| --- | --- | --- | --- | --- |
| MVP必须有 | AC-01 到 AC-07 的行为；三枪、三近战、一秒护盾；九条增益的空池 | 没有这些就不是这条循环 | 调试条或录屏能对上 Cut-001 | 退回站圈，或退回只在关底三选一 |
| Vertical Slice应该有 | 三枪分得开；三近战分得开；三流派分得开；插旗手感；增援压力；现成据点建筑 | 规则通了之后才值得再开一局 | 口头能区分枪、近战和流派 | 切片不能只剩血条 |
| Demo后再做 | 分支路线；每关独立身份；更多关卡；更多枪械和词条；更多敌人种类 | 依赖循环已经被玩懂 | 现在不验证 | 关卡选择会膨胀成地图 |
| 宣传概念暂不开发 | 故事文案；战役宣传图；阵营角色叙事 | 帮助讲「往城里推进」 | 口头讲得清即可 | 做成可玩大地图就会滑向战地 |
| 建议砍掉 | 战地式征服；多人；站圈；全图破坏；清完再选卡；定制建筑；连携进化；局外养成；±120/+12/+20 | 和 Cut-001 冲突，或是已作废草稿 | 不验证 | 范围失控，或把勘误写回去 |
