# 恐惧敌人：引魂者与紫色追魂

2026-11-15，Issue #213。基于已合并白色圣殿及轻柔水声的 main `a5cb545`。用户要求类似此前披斗篷的敌人，手持镰刀，召出移动较快的小紫色幽魂，幽魂接近一定距离后攻击。

## 当前可玩行为

引魂者复用本项目已有破损斗篷、兜帽和晶体身体，改用暗紫材质并增加原创曲刃长镰刀。它沿现有导航靠近玩家，在视线可达时蓄势召出最多3只紫色追魂；玩家靠近时会用镰刀攻击。召唤前摇使用紫色亮纹与现有低音锁定声提示，不添加枪声。

紫色追魂可以飞越断桥，快速追向玩家；接近后停顿、缓慢膨胀，再朝锁定方向短扑。玩家可以射杀、用现有攻击/增益击退或冻结它们，也能横向走位、后撤和利用实体掩体躲避。幽魂一次扑击结束就消失，命中最多结算一次伤害。

## 正式房间接入

第一恐惧小关保留原3名敌人，在右后侧岛 `(7,0.05,-8)` 加1名引魂者，共4名。第二小关保留原4名敌人，在左高台外侧 `(-9.8,1.25,0)` 加1名，共5名；出生位置留出坡道中间的通路。Boss房仍为单独审判之瞳战。

高空的6只淡白景观幽魂继续存在，与这些可攻击的紫色追魂区分。白色圣殿尺寸、入口到出口36米、翻板、坠落30HP、随机领域顺序和已合并的新水声保持。

## 生命周期与实现

`FearReaper` 是正常 `Enemy`，由 `RealmStage` 注册、参与清场和正常击杀收益。它持有追魂的弱引用；追魂与主人同属房间，并接收目标、伤害倍率与预警状态。`FearWisp` 通过已有注册事件进入增益命中/状态系统，有真实Health、枪击Hitbox和WORLD移动碰撞；不加入Stage敌人计数，不发普通击杀奖励，避免召唤物拖住出口或反复刷击杀收益。

引魂者死亡、撤退、玩家死亡、追魂寿命结束、扑击完成或离开房间都会清理追魂。固定3只上限与共享简单网格/材质限制额外开销；追魂没有动态灯、导航烘焙或物理碎片。引魂者死亡复用加载阶段准备好的恐惧碎片碰撞，不在击杀时重新生成凸包。

镰刀挂在真实右手骨骼上，独立武器轴负责施法与挥砍动作；没有新增第三方模型、纹理或音频。代码、原生截图与验证见 [取证记录](../proof/fear-reaper/README.md)。当前数值为可调试玩默认，跨设备性能和真人难度反馈仍待收集。
