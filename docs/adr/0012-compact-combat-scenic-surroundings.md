# ADR 0012：紧凑战斗核心与宏大外围景观

- 日期：2026-11-08
- 状态：已实现并完成自动/原生自检；继续在 #97 / 草稿 PR #98 上等待试玩与评审

## 原因

用户试玩指出当前地图过大，走到据点浪费时间；要求主战场接近以前的大小，旁边景观宏大好看。旧灰盒地板虽然为 60×60 米，但两关出生到据点只有 22/24 米（z14/16→-8）。首次整合改为 103 米（z55→-48），普通 4.4 米/秒走路的理论时间由约 5 秒增加到 23.4 秒，实际绕路还会更久。

## 当前修订

两小关可走核心为 40×48 米，出生和据点恢复 z14/16→-8，目标距离为 22/24 米。主路短而连续，侧路与高台提供选择；不靠加玩家移速、传送或改据点规则减少耗时。地形和掩体按米重排，不把整个场景等比缩放，避免角色、掩体、坡高和碰撞比例失真。

外围柱廊、浮岛与云海沿用大尺度，作为不可走的景观；真实地板、碰撞、导航、掩体点、守卫与增援仅服务紧凑核心。Boss 实际战斗台直径 50 米，外侧 92 米圣殿与巨环/钟摆保留观感。玩家能近距离交火并快速走到目标，仍可从战斗区看到宏大建筑。

守卫4/6、Boss6名小怪、四连弹与据点/增援/选卡/胜负规则不变。当前草稿仍使用原型Boss。

## 验证

实测普通 Player（4.4m/s、Stats倍率1、无冲刺）到锤程为4.30/4.72秒；8组依赖地图回归、布局55项、增援63项、整局headless130/原生140项、原生四连发25项通过。固定种子6次实战全胜且同种子哈希一致。独立验证远景无物理/导航、三图各96方向高位玩家扫掠均被防坠边界拦住。数据与画面见 [紧凑战场证明](../proof/sloth-compact/README.md)。此前宽场证据和备用包保持历史记录，不能作为紧凑版通过依据。
