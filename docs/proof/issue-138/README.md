# 怠惰领域与三变体（#138）

本票提供独立的暖琥珀怠惰环境、三种新敌人及可玩验收场。旧 `SlothEnemy`、披风备用版及其既有测试场景未被替换；四领域地图装配使用新 `SlothRealmEnemy` 场景，避免把旧敌人的 25% 减速误当作新版的禁冲刺。

## 试玩

在 Godot 4.7.2 打开 `tests/sloth_realm_bench.tscn` 运行。WASD 移动、鼠标枪击、右键瞄准、V 短刃、Shift 冲刺、F8 重置。场地为 40×48 米，出生点 (0,0,16)，通道中线与出口 (0,0,-20) 连通；掩体、柱体有 WORLD 碰撞，外侧悬浮块和断阶为景观，不参与导航。环境脚本 `environments/sloth/realm.gd` 暴露 `boss_arena`，地图生成器可复用同一空间语汇装配普通房及 Boss 房。

## 实际机制与默认参数

| 敌人 | 实现 |
|---|---|
| 迟滞者 | 110 HP、2.2 m/s。1.2 秒凝聚锁定目标位置，再生成四枚静止晶体；分别等待 0.8/0.93/1.06/1.19 秒后以 18 m/s 释放，单枚 10 点伤害，释放后不追踪。 |
| 锚定者 | 190 HP、双腿融入琥珀基座，不主动走动。8 米水平半径、±2.2 米高度且 WORLD 视线通畅时禁止冲刺，并降低移动到 55%。离开、掩体阻隔、死亡、退出或绝对时停均清除此来源。 |
| 退缩者 | 125 HP、普通移动 2.8 m/s。真实受伤后撤 1.8 秒，以 1.8 倍移动速度通过 CharacterBody 碰撞后退；期间每 1.15 秒发射一枚 0.35 秒悬停、13 m/s 的回马枪，9 伤害，最多追踪 1.1 秒。 |

敌弹继承真实 `Projectile` 扫掠、Hitbox、弹反与 Boon 局部时间接口。景观、身体、服饰材质均逐实例设置，原 GLB 和原红色材质不变。晶体人体仍有 24 骨，死亡时从当前姿势生成全部 56 个原始碎片，各自为 WORLD 碰撞的 RigidBody3D，2.4 秒统一回收；仅外观散布使用确定性索引，不消耗玩法 RNG。

新 `SlothRealmVisual` 复用原身体与动画，改为琥珀材质、下垂前臂、基座或内抱姿态。环境包含冻结巨环、钟摆、束缚线、缓慢微尘和两个暖色 Rest Zone；本票不自动恢复被其他领域剥夺的能力。

- 共享 Player 约束另见同目录 `shared-contract.md`；根实现的 15 项共享验证、旧 Dash 与 64 项 Boon 管道日志一并保留。

- 原生 Forward+ / RTX 4060 Laptop 两图来自同一实际试玩场的脚本布置，已打开检查：`realm-overview.png` 展示可走空间，`amber-variants.png` 展示三个素体变体与实际 8 米范围环。图中为固定镜头、敌人停驻布景，战斗行为由上述真实物理测试覆盖。
- 最终导入、行为测试和原生截图日志无 ERROR、WARNING 或退出泄漏。

数值为明确的首次试玩默认。脚本验证和截图不等同于人工手感、可读性或全硬件性能验收。
