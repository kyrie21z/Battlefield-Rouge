# ADR 0003：锤砸占点的节拍、冷却与按键

日期：2026-10-25　状态：已采纳（实现 Issue #5 时补的规则，待试玩确认）

## 背景

[Cut-001b](../Cut-001b.md) 锁定了三个数：窗口 ±150ms、普通锤 +8%、完美 ×1.5。但它没有说“命中时刻”到底是什么、锤多久能挥一次、锤用哪个键。没有这几条，完美打击做不出来。

[03_rules.md](../bible/03_rules.md) 把“锤的按键”列在仍未锁定里。Cut-001b 又写明配置只保留三个数，所以下面这些补充规则不能放进配置。

## 决定

1. **命中时刻是据点上的节拍。** 据点开放后每 `CapturePoint.BEAT_PERIOD` = 1.0 秒出现一次，首次在开放后 0.5 秒。挥锤时刻与最近一次命中时刻的差，绝对值 ≤ `perfect_window_ms` 就是完美打击。HUD 的节拍条把窗口画成金色区间，标记每秒扫过一遍。
2. **判定用按键那一刻。** 画面上锤在按下后约 60ms 落到据点上，判定不加这段延迟，否则玩家得提前按键。
3. **挥锤冷却 0.9 秒**（`Hammer.SWING_COOLDOWN`）。没有冷却，乱按比卡点更快，完美打击就没有意义。按冷却间隔连按时，相位每次错开 0.1 秒，10 次里约 3 次落进窗口，平均每次 9.2%，约 10.2%/秒。每拍一次完美是 12%/秒，只快约 18%。
4. **锤用 E 键**（`hammer` 动作）。临时的，改键只改 `autoload/input_map_setup.gd`。
5. **进度只增不减。** 不再有站圈时的衰减。这也满足“增援不回退进度”。
6. **清守卫之前据点锁定。** 锁定时挥锤只有挥空声，不加进度（Priority_Backlog：清零后锤击才加进度）。
7. **满进度后先插旗，1.4 秒后再弹出选择或胜利界面。** 选择界面会暂停整棵树，不等的话旗杆升起的动画被冻住，AC-01 的“插旗”看不到。
8. **反馈分开。** 完美打击：金色高音、建筑金色发光加灯光爆闪、屏幕金色闪、大号金色文字。普通锤击：钝响、短促白光、灰色小字并标出偏早或偏晚多少毫秒。

节拍周期（1.0 秒）和冷却（0.9 秒）是代码常量，不进 `capture_config.tres`。

## 不在这次范围

增援、冲击波、进关选择、Boss、九条增益、三枪三近战。占点建筑还是灰盒方块，锤和旗是占位模型。

## 后果

- 试玩觉得节拍太快或太慢，改常量，并在本文追加一条。想把它们做成配置，要先改 Cut-001b，因为它规定配置只有三个数。
- 窗口 150ms 占节拍周期的 30%，所以连按也有约三成挥锤是完美打击。技巧相对连按只快约 18%，优势不大。想拉大差距有两条路：把窗口调窄（在配置里改）；或把冷却加长到接近 1.0 秒，不过那样相位几乎不漂移，连按会长时间全中或全不中。
- 完美打击带来的提速取决于冷却、周期和窗口三者，不只是 ×1.5。冷却短于 0.7 秒时连按反而比每拍一次完美更快（约 13%/秒），所以别把冷却调得太短。

## 试玩反馈

2026-10-25，Kyrie 玩过后的反馈：**完美打击的收益太小。** 数据与此一致：

| 窗口 | 倍率 | 连按（%/秒） | 每拍卡点（%/秒） | 卡点比连按快 | 满进度用时（连按 / 卡点） |
| --- | --- | --- | --- | --- | --- |
| ±150ms | ×1.5（当前） | 10.2 | 12.0 | +17% | 9.8 秒 / 8.3 秒 |
| ±150ms | ×2.0 | 11.6 | 16.0 | +38% | 8.7 秒 / 6.2 秒 |
| ±150ms | ×3.0 | 14.2 | 24.0 | +69% | 7.0 秒 / 4.2 秒 |
| ±100ms | ×2.0 | 10.9 | 16.0 | +46% | 9.2 秒 / 6.2 秒 |
| ±50ms | ×2.0 | 9.8 | 16.0 | +64% | 10.2 秒 / 6.2 秒 |

按冷却 0.9 秒、周期 1.0 秒、普通 8% 算，连按的相位每次错开 0.1 秒，所以不瞄准也有约三成落进窗口。窗口越宽、倍率越低，连按越不吃亏，完美打击的“技巧奖励”就越小。

只改 `zone/capture_config.tres` 里的三个数就能调，不动规则，符合 Cut-001b“试玩后只改变量”。要不要调、调成多少，由 Cut-001b 的负责人定。冷却和周期是代码常量，改它们属于改规则，要先改 Cut-001b。窗口外不扣进度（Cut-001b 规定“只记普通进度”），所以不能用惩罚来拉开差距。
