# Epic 1 武器作者文件

两个模型均由本目录的 `generate.py` 在真实 Blender 中创建并导出，按 `docs/assets/` 的用户转面图和第 8 节正文尺寸重新建模，风格参考 SUPERHOT 的硬朗轮廓与平面反光；没有复制其他游戏素材。材质为程序创建的纯色 PBR，不依赖贴图。

```sh
blender --background --python tools/epic1_models/generate.py
```

交付包含可编辑的 `obsidian_pistol.blend`、`mind_blade.blend`，以及 `manifest.json`。实际生成版本为 Blender 5.2.3 LTS；`.gdignore` 避免 Godot 自动处理这些作者文件。生成器覆盖自己生成的同名输出，不读写已有 `art_source/`。

| 模型 | Blender 原始三角/四边形 | GLB 三角形 | 尺寸 |
| --- | ---: | ---: | --- |
| 黑晶手枪 | 120 | 180 | 长 220mm，高 135mm，宽/握把厚度 32mm |
| 意志短刃 | 45 | 70 | 全长 400mm，刃宽 40mm，厚度 15mm，握持点到刀尖 340mm |

用户后续明确“面数可以增加，最重要的是质感”，因此源面数不设旧版 40/25 硬上限；保留低模硬朗轮廓所需切角、凹槽和双坡面，如实报告几何。正文尺寸及无护圈要求优先于参考图里的冲突标注。手枪包含 10mm 深六角凹孔、阶梯滑套、斜握把和 0.7mm 暗金缝；短刃采用 Tanto 双坡菱形截面、八角极简柄、0.8mm 脊线能量缝。

所有源面均为三角形或四边形，`use_smooth = false`。导出器独立统计最终 GLB 索引数，验证三角形数量与 Blender 三角化结果相同；逐对象统计、轴转换、尺寸和 GLB SHA-256 见 manifest。源多边形数与渲染三角形数分别报告，不混用。

源文件采用 Blender -Y 向前、Z 向上。导出时临时绕 Z 旋转 180°并烘焙网格，使 Blender 的 Y-up glTF 转换最终得到 Godot -Z 向前、+Y 向上；`.blend` 本身保留原作者坐标。手枪根原点在实际握把包围盒中心，每一重组块的局部原点在自己的几何包围盒中心。短刃握持点为根原点，厚度沿 X、刀背朝 +Y、刃口朝 -Y。

可视验收使用 Godot 原生渲染的战斗测试台第一人称截图，结构和面数测试不代替轮廓/比例检查。
