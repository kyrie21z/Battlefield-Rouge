# 双重心智共鸣原生取证

入口：`tests/dual_boons_proof.tscn`，Godot 4.7.2 Forward+，RTX 4060。
两张图均运行真实 Player、SlothEnemy、Health、Hitbox、Projectile 与赐福脚本。
白色地面、灯光和说明文字仅用于取证布景；深潭、泥沼、晶体、时钟、伤害飘字和泪晶全部由正式机制生成。

- `01-tearful-panic.png`：装备恐惧枪、悲伤刀与惊惧泪海后，真实手枪射线命中 `FrontFlaw`。
  该次命中造成 91 点伤害、破绽移至背部、三名敌人都获得 5 层溶蚀，旁侧敌人通过 CharacterBody 物理移动聚拢。
  画面中的三颗泪晶由满层溶蚀生成；深潭通过 WORLD 射线贴地。
- `02-suffocating-mire.png`：先用真实怠惰冲刺在起终点留下光环，再替换冲刺槽，以真实悲伤冲刺移动生成水带。
  两段冲刺均验证实际位移超过 3 米。保留怠惰枪与悲伤刀作为双系前置，泥沼覆盖水带与光环区域；
  两个区域内敌人攻速均为 50%，区外敌人为 100%。实际敌弹以 20 m/s 原速出发，0.1 秒只移动 0.1 米，即 5% 速度。

为了稳定展示，敌人生命设为 5000，关闭披风随机闪避，不注入战斗事件、不手绘技能效果；
效果触发和数值/位移断言结束后才暂停画面截图。模型与原始材质不变。
这两张静态图展示真实运行状态，不代替六组组合的行为回归或战区手感验收。

运行时用户参数：`--mode=tearful` 或 `--mode=mire`，`--out=<输出目录>`。
对应日志为 `tearful-native.log` 与 `mire-native.log`。
