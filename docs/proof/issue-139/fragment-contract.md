# 核心碎片与剥夺分离

用户已明确：拾取碎片后立即启用独立能力，普通机制保持剥夺。`Player/PsycheFragments` 接收战区注入的失去项与碎片集合，不读取 RunState；拾取物通过玩家距离与 WORLD 视线判定，仅授予一次，collected 信号由战区保存。

沉睡碎片默认受伤、开火、挥刃、造成伤害后5秒恢复，之后每秒2 HP；12米内仍有可见活敌时不能靠停火回血。暂停、死亡不回血，拾取不删除失去怠惰项，Rest Zone 的环境关闭状态不受碎片影响。独立测试12项通过，覆盖隔墙/远处拒绝拾取、一次授予、真实战斗与暂停、近敌、死亡与恢复去重；日志为 slumber-fragment.log。
