# SPEC · 规格边界

已锁定的写在表里。空着的保持待定。临时默认做成配置，不散落成多处魔法数。出处：[Cut-001](../Cut-001.md)、[03_rules.md](03_rules.md)。

## 一句话

Godot 4.7.2 第一人称射击肉鸽：线性三关，小关先清零再砸点，进关前和关末各选 1 条增益，Boss 一波后胜利。

## 技术

- 引擎：Godot 4.7.2 标准版，Forward+，Jolt。不用 .NET 版。
- 语言：GDScript。
- 已有输入绑定以 `autoload/input_map_setup.gd` 为准。近战、护盾、锤、切换武器的键未定。
- 增益只通过 `Stats` 生效。谁可以改本局状态，见 [ARCHITECTURE.md](../../ARCHITECTURE.md)。

## 配置默认（临时）

| 配置 | 默认 | 验收 |
| --- | --- | --- |
| 完美窗口 | 命中时刻 ±150ms | AC-04 |
| 普通锤击进度 | +8% | AC-03 |
| 完美进度倍率 | ×1.5 | AC-04 |
| 完美反馈 | 专用音效 + 闪光 | AC-04 |
| 窗口外 | 只有 +8%，没有专用反馈 | AC-04 |
| 增援对进度 | 不回退 | AC-03 |
| 占满 | 100% 插旗 + 冲击波 | AC-05 |

不存在 ±120ms、+12%、+20% 这三项配置。

## 已锁定、不是这张配置表的部分

| 项 | 值 |
| --- | --- |
| 关卡 | 小关 2 + Boss 1。解锁：小关 1 → 小关 2 → Boss（AC-01） |
| 小关过段 | 当前波次敌人归零后才能砸（AC-02） |
| Boss | 一波城市核心；锤击配置同上；插旗后胜利且不选增益 |
| 枪 | 步枪、狙击枪、霰弹枪 |
| 近战定性 | 匕首快/近/低；斧慢/中/高；太刀中/远/中 |
| 技能 | 自身护盾，无敌 1 秒 |
| 增益池 | 9 条。流派与占位名见 [03_rules.md](03_rules.md) |
| 选择 | 进关前 1 条；小关结束再 1 条；叠加；Boss 后不选。打完 5 次（AC-06） |
| 死亡 | 增益与本局解锁清空，从第 1 关重开 |
| 核对 | 调试条或录屏（AC-07） |
