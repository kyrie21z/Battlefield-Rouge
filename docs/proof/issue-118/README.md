# #118 恐惧完整十二卡池

九张特质与三个核心共用 `FearEffect`，由 `FearTraitsRuntime` 扩展；只实例化一个核心处理器。
卡池为 `buffs/resources/fear/pool.tres`，资源中记录全部新增默认参数。

| 特质 | 实际行为与默认参数 |
| --- | --- |
| 远距恐慌 | 暴击伤害系数在 12→36 米线性从 1→1.75，36 米后封顶。作用于破绽、原生头部及 Stats 随机暴击。真实玩家飞弹与弹反弹速 ×1.5，由共享管线只消费一次；原手枪 hitscan 保持即时。 |
| 疑神疑鬼 | 对惊悸敌人每次真实出弹用管理器种子流掷 35%；成功时朝最近无遮挡同类开火，允许友伤，对玩家伤害为零。 |
| 第六感 | 相机视锥外的出弹触发 0.8 秒紫色边缘提示；预计越过现有护盾与生命的伤害才掷 35%，免伤并用玩家真实胶囊扫掠向后移动最多 3 米。 |
| 碎面蔓延 | 自然攻击碎面向可见 8 米内最近两名其他敌人附加 4 秒惊悸；衍生命中不再次蔓延。 |
| 草木皆兵 | 严格低于 50% 生命时，移速 ×1.25、暴击率 +0.20、冲刺充能速度 ×1.4；恢复至阈值或移除卡牌即撤销同一 Stats 来源。 |
| 惊惶暴露 | 凸包与显示晶面面积 ×1.5，因此横纵尺寸各 ×√1.5。跳弹/溅射真实接触点允许 0.12 米边缘擦中；可与其他具名面积来源叠乘并独立撤回。 |
| 绝命处决 | 前置枪或刀；敌人严格低于 35% 且击碎破绽时固定 5 倍基础伤害。致命命中经过正常 Health 死亡/粉碎流程；不会额外补足伤害或越过无敌。 |
| 幽邃致盲 | 前置冲刺或任一恐惧次级特质；残影爆炸或碎面使可见 8 米内敌人 2 秒无法行动。采用敌人局部状态，不停止玩家时钟。 |
| 全景惊惧 | 前置两张恐惧特质；之后注册的新敌人立即获得永久惊悸与前后双面。每次碎面发射基础 35、速度 36 m/s 的真实追踪晶弹，必暴击；该晶弹不再生成同类晶弹，所有衍生深度受限。移除传奇撤回永久标记，保留另行获得的有限惊悸时长。 |

新增图形与提示均为程序生成，不引入外部素材或改变主角黑色晶体接缝。
所有计时受暂停影响；玩家实际死亡、换场和管理器清理均撤销临时状态、仇恨、追踪回调和屏幕提示。

验证：`tests/fear_boon_traits_test.tscn`，Godot 4.7.2，`--headless --fixed-fps 60`。
39 项行为检查通过，包含真实飞弹伤及友伤、身体碰撞挡墙、护盾下致命预判、概率成功/失败路径、
距离取样、五倍非致命/致命分支、面积边缘、蔓延数量、盲目暂停/到期、传奇递归与实际死亡清理，以及持续伤害不得继承前次破绽/背刺标记。
`traits-test.log` 记录结果；#117 的 18 项核心检查同时回归。
