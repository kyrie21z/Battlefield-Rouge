# 恐惧幽魂表情与爬行怪坡道修复

2026-11-16，Issue #216，基于 main `5ac99af`。用户提供了平时/靠近时张嘴的幽灵参考，并补充牙齿位置与模型细节需要调整；同时要求修复爬行怪不能过坡道攻击，提高主动性。

## 当前幽魂模型与动画

紫色追魂仍为可射杀的飞行召唤物。新增原创圆顶衣身、柔和飘动的波浪下摆、眼白与瞳孔、嘴缘、上下獠牙和连续卷舌曲面。参考图仅用于表情变化方向，没有把参考图片、卡框或绿色叶片制作成游戏资产。

平时保持小嘴与较大瞳孔，轻微漂浮并眨眼；进入原0.55秒扑击前摇后，眼睛抬高、瞳孔收缩，嘴部连续张开，牙齿从嘴缘向内伸出、舌头探出弯曲，衣身稍拉长前倾。扑击时保持张嘴形态。未采用整张模型突然替换或全屏闪光。

牙根固定在嘴缘内侧，动画只改变牙长，不把整组牙齿从嘴中央缩放到边缘。上排长獠牙、下排短牙，牙尖均向嘴内倾斜，避免牙齿伸到嘴唇外。舌头为连续光滑曲面，嘴部前移以免平时小嘴被衣身遮住。命中框使用0.44米半径、1.5米高的胶囊，覆盖张嘴后抬高的上半张脸；移动碰撞仍使用原0.30米球形。

模型和网格在加载时准备、实例共享，只有材质参数和少量表情节点逐帧更新。动画时间由幽魂自身物理逻辑推进，暂停/冻结时停止；失去恐惧时不提前显示张嘴预警，实际扑击仍有攻击形态。数量上限3、18基础HP、7米/秒、1.8米触发、0.55秒前摇和8基础伤害保持。

## 爬行怪：原因与修复

真实第二恐惧房间可复现：怪物停在坡口约 `(9.13,-0.01,8.05)`，导航下一点却在约 `(9.08,0.71,8.03)`。水平距离已经很近，但导航按包含高度的距离判断仍未抵达，反复停留在同一点。原检查只验证“烘焙路径存在”，不足以证明实际演员能走上去。

给爬行怪的NavigationAgent设置 `path_height_offset=0.5`，校正烘焙路径相对地面的高度偏差，使它能推进到后续坡道路径点；使用真实WORLD碰撞爬坡，没有传送或穿透地面。

| 爬行怪参数 | 之前 | 当前 |
| --- | --- | --- |
| 追击移速 | 4.2米/秒 | 5.0米/秒 |
| 初始等待 | 0.6秒 | 0.35秒 |
| 扑击前摇 | 0.85秒 | 0.65秒 |
| 扑击后冷却 | 3.0秒 | 1.6秒 |
| 单次基础伤害 | 22 | 22 |

只调整爬行怪，窥视者和颤影者保持原节奏。已有实体掩体、扑击前摇、难度倍率和暂停/增益状态继续生效；没有提高扑击伤害。

原生验证包括左右两座侧台、前后共4个坡口的实际爬坡与高台命中、反向下坡和连续进攻。取证、同视角变形动图及验证限制见 [本轮记录](../proof/fear-morph/README.md)。

## 2026-11-16：战斗瞬间卡顿（#219）

引魂者进房准备3只未激活追魂，并用4帧1%大小的实际绘制准备完整张嘴材质。备用演员不参与逻辑、碰撞、增益目标或清场计数；召唤才注入当前玩家、深度倍率及预警剥夺并注册。死亡/消散的演员仍释放，不重复利用携带旧状态的演员；空位每帧准备1只。活追魂上限、攻击数值和表情保持。

普通恐惧敌人、引魂者及审判之瞳在加载时预建56块树外死亡碎片，死亡时才取当前骨骼姿态、加入物理世界并散开。2.4秒后同时隐藏、关闭碰撞，随后每物理帧释放8块，完整回收。恐惧房同时提前读取并保留馈赠目录；选卡资格、随机抽取和替换仍在实际领取时计算。

这是将准备工作移到加载阶段，以增加备用节点/资源常驻为代价，保留真实碎片和幽魂细节。原生测量、残余奖励UI开销及生命周期回归见 [性能记录](../proof/fear-hitches/README.md)。
