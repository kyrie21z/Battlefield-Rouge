# Floor I: Sloth（怠惰之境）

> 2026-11-18 正式关修订。两小关使用 40×48 米庭院，门扉距出生点南北方向 36 米。高空巨钟、断拱和钟楼扩大剪影，两侧以高台、短坡和掩体增加战斗路线。三类守卫的技能以 PR #92 的旧设计为基底。第一房与第二房分别有 2/3 名持杖迟滞者、1/2 名锚定者、各 1 名退缩者与 1 名凝胶异形。详见[当前实现和验证](../proof/sloth-sanctum-combat/README.md)。以下保留原 v0.1 草案。

> 同日配色修订。正式怠惰守卫的身体与攻击采用金黄色主题。迟滞者穿黑色兜帽和斗篷，边缘用细金线，露出的晶体身体通体金色。锁向时晶体由琥珀变为浅金，黏液使用蜂蜜色。场景保留白石，关闭的门扉用暖金，与悬钟和地面镶条相呼应。

> 同日凝胶异形攻击修订。1.15 秒蓄力末尾锁定玩家脚下的地面，抛球落地后摊开成最大半径约 3.2 米的金色胶池，持续 3.5 秒。踩入步行减速 35%，每 0.25 秒结算 2.5 点基础伤害，离开或跳离表面即停止。掩体挡住或弹反空中的黏液球可阻止胶池形成。

> 同日修复锚定者超距或失去视线时原地待机，施法之前会寻路绕开掩体，退缩者失去视线时会继续追近。锚定者的定点领域显示金色刻度与转动指针，步行减速 25% 时出现屏幕边缘反馈。退缩者用贴地的双层金波标出扩散前沿，保留 44° 安全缺口。失去恐惧后仍隐藏前摇提示，已释放的两种攻击继续显示。

## 0. 阅读约定与决策状态

- **【共识】**：讨论中已经明确认可的主题与大方向。
- **【设计提案】**：本文提出的具体玩法、形象与表现方案；尚需三人团队评审。
- **【原型参数】**：便于第一次试玩的初始估值，绝非最终数值。
- **【待定】**：需通过试玩或进一步讨论决定。

### 当前已明确的共识

1. 玩家最初**相信应当消灭心魔**，不应一开场被告知“接纳自我”的结论。
2. 第一层围绕 **Sloth（怠惰）**：玩家深入数个小关，最后对抗象征怠惰的 Boss。
3. Boss 首选直观的**蜷缩着的巨人**，而不是纯非人形几何核心。
4. 场景与敌人采用**简单、抽象、白模与线条感**，通过行为表达心理主题。
5. 三种敌人构想获得正面认可：**迟滞者、锚定者、退缩者**。是否全部纳入首个可玩版本仍需范围评审。
6. 采用战后 **B + C**：Sloth 败后世界过度运转、休憩空间消失；玩家发现 **Rest Fragment**，第一次对“彻底清除怠惰”产生怀疑。
7. **Pride / The Crown** 是戴在玩家头顶、能说话且真诚希望玩家变好的引导者，不是故意欺骗玩家的反派。

## 1. 本层的一句话体验

> **在一个凝固的世界中，玩家奋力恢复流动；当停滞终于被清除，却发现自己也失去了停下来休息的地方。**

### 1.1 主题边界

本层不应宣扬“逃避责任就是休息”或“怠惰没有危害”。Sloth 同时包含**停滞 / 逃避的阻碍**与**休息 / 恢复的需求**。玩家在第一层只需发现自己把两者混为一谈，而不是立刻实现完整和解。

### 1.2 目标体验

| 阶段 | 玩家初始理解 | 关卡应提供的体验 |
| --- | --- | --- |
| 进入 | “怠惰让我停滞，我必须清除它” | 冻结的空间、阻碍推进的敌人、Pride 有效的指导 |
| 战斗 | “只要继续行动就能摆脱它” | 延迟攻击、区域约束、逼迫变换站位 |
| Boss | “这个沉睡巨人就是停滞的根源” | 强烈的 FPS Boss 挑战；Boss 以防御、排斥外界为主 |
| 胜利 | “世界终于能够前进” | 停滞解除，获得明确战斗成就感 |
| 异样 | “为什么一切变得无法停止？” | 世界过快运转，原有休憩区逐一熄灭 |
| 发现 | “它真的毫无价值吗？” | Rest Fragment 证明被清除者留下了必要的恢复能力 |

**本层最终叙事目标：** 玩家提出“我是不是遗漏了什么”，而不是“我已经完全理解并接纳 Sloth”。

## 2. 关卡结构与空间组织

### 2.1 建议原型流程

为了便于三人团队验证，先做**可控的固定流程**，不在 v0.1 承诺完整随机地牢生成。未来可把房间模板组成 Hades 式分支路径。

| 节点 | 暂定名称 | 核心内容 | 设计目的 |
| --- | --- | --- | --- |
| 进入段 | The Threshold / 静滞之门 | Pride 的首次引导、远眺凝固建筑 | 交代消灭 Sloth 的目标与视觉语法 |
| Room 1 | Stagnant Plaza / 停滞广场 | 迟滞者；低强度掩体战斗 | 学会识别“延迟才爆发”的攻击 |
| Room 2 | Anchored Corridor / 锚定回廊 | 锚定者 + 少量迟滞者 | 学会争夺空间、优先击杀限制走位的敌人 |
| Room 3 | Unfinished Court / 未完成之庭 | 两种敌人混合；退缩者精英（可裁剪） | 组合考验；首次发现可用的 Rest Zone |
| 过渡段 | Quiet Passage / 静息回廊 | 明确、短暂的休憩空间与 Boss 门 | 让玩家记住“休息曾经是可能的” |
| Boss | Sleeping Colossus / 沉眠巨像 | 环境控制型双阶段战斗 | 将停滞与逃避升格为整个空间的力量 |
| 战后段 | Aftermath / 过度运转 | 世界加速、休憩区熄灭、Rest Fragment | 用交互结果而非说教完成第一层反转 |

**【原型参数】** 单次完整通关目标暂估 10–18 分钟，仅供排期和试玩比较，实际以战斗节奏为准。失败重开与房间随机顺序机制【待定】。

### 2.2 FPS 空间与地形原则

- **战斗脚下必须可信且清楚**：浮空几何可以大量存在于远景；主路线仍应有连续、可辨认的地面，避免把射击原型变成跳跃平台挑战。
- **明确前进方向**：利用超大环形结构、悬停钟摆和暖色远景做地标，减少迷路。
- **避免白模融成一片**：地面、敌人、掩体、可通行边缘需通过灰阶、投影、边线或局部强调色区分。
- **从教学到组合**：Room 1 只需要应对一种攻击规律；Room 2 引入移动限制；Room 3 才组合两者。
- **掩体有价值但不万能**：部分延迟弹道可以用掩体规避，锚定区域要求玩家改变掩体点位。

**【设计提案】** 小关以开放但不巨大的白色平台与断裂回廊构成；战斗面积应支持横向绕行和短距离冲刺，而不是狭窄直线枪廊。

## 3. 美术方向：The Stillness

### 3.1 视觉母题

**【共识】** 整体采用**低细节白模 / 几何块面 / 清晰线条**的抽象精神世界。

**【设计提案】** 使用三个重复出现、可被玩家记住的符号：

1. **停滞结构**：悬浮未落的建筑块、停在半途的楼梯、固定的钟摆与环形机构。
2. **束缚的线**：从结构、敌人与地面之间拉出的少量冷灰色直线，表示被固定、被拖延。
3. **休憩的光**：极少量温暖的琥珀色光域，用于 Rest Zone 和 Rest Fragment，和主体冷灰白形成对比。

全层避免现实城市建筑、真实军事道具、写实废墟材质和过多机械细节。大块白色实体应靠**体积、负空间和光照**构成气氛。

### 3.2 场景状态变化（战前 vs. 战后）

| 维度 | 战前：静滞 | Boss 败后：过度运转 |
| --- | --- | --- |
| 钟摆 / 巨环 | 几乎静止，偶尔缓慢颤动 | 快速连续转动，速度逐渐提高 |
| 悬浮碎片 | 停在空中 | 开始流动 / 沿预设轨迹旋转 |
| 环境声 | 稀疏低频、远处轻微回声 | 密集节拍、连续机械脉冲 |
| Rest Zone | 暖光可见，可交互、可恢复 | 暖光依次熄灭，原有交互失效 |
| Pride 解读 | “这里需要恢复前进” | 最初认为清除已取得成效 |

**重点：** 战后变化应发生在玩家**已经经过或主动使用过**的物体上；否则“失去了休息空间”不会被理解为损失。

### 3.3 声音原则

- 普通战斗音效简洁、干净，攻击预警优先级高于环境氛围。
- 延迟弹丸悬停时有独特的充能音，释放时有清楚的触发音。
- Rest Zone 以低噪声、温暖的声场表现安全。
- Boss 死后不要只追求更响、更快；用从寂静到持续压力的**听觉对比**表达过度运转。
- 必须提供降低环境噪声的选项，避免强烈重复声造成实际不适。

## 4. 敌人设计

敌人不是“懒得攻击的士兵”，而是**拖延、惯性、逃避**三种状态的几何化身。

### 4.1 The Lingerer — 迟滞者

**定位**：基础远程敌人 / 拖延（Delay）
**视觉**：灰白色低头人形；身体略微前倾，四肢由错位几何片连接；身后拖着少量细黑线。脸不需要细节。

**技能：Delayed Shot（延迟弹幕）**

1. 迟滞者瞄准玩家当前或可预测的短期位置，播放明确的预备动作。
2. 发射一枚深色几何弹丸；弹丸在指定位置**悬停**。
3. 短暂延迟后弹丸沿**已确定方向**高速释放，玩家可以预判并躲避。

**反制**：横向位移、利用掩体、趁悬停阶段击杀本体；弹丸**不能在最后一刻无提示追踪**玩家。

**【原型参数】** 悬停 0.8–1.3 秒；首个房间同屏建议最多 2–3 个迟滞者，需试玩调整。

**表达**：被一再推迟的问题会积累，但不会凭空消失。

### 4.2 The Anchor — 锚定者

**定位**：固定式区域控制敌人 / 惯性（Inertia）
**视觉**：无面部的悬浮方碑或多面体，数条几何线连接地面；底部有规则环形投影。主要靠高度、锚线和光圈区别于迟滞者。

**技能：Stasis Field（沉滞领域）**

1. 地面首先显示明显的圆形预警区。
2. 预警结束后生成短时减速领域，限制玩家走位。
3. 锚定者本体暴露清楚的弱点，击破可解除领域。

**反制**：预先离开区域、集火弱点、利用掩体转点。领域应影响位置选择，不能反复剥夺移动控制。

**【原型参数】** 预警 ≥0.8 秒、减速幅度起始建议 20%–25%、单次持续约 2–3 秒。多个领域**不叠加减速**，Boss 技能也遵守减速上限。

**表达**：惯性使人维持原状；改变位置才能脱离约束。

### 4.3 The Recluse — 退缩者

**定位**：精英敌人 / 逃避（Withdrawal）
**视觉**：裹在不对称白灰几何外壳里的蜷缩人形 / 茧，内部仅有一道暖色或暗色的细裂缝；静止时像一块封闭雕塑。

**技能：Withdrawal & Recoil（封闭与反击）**

1. 大部分时间缩入厚重外壳，承受伤害较低（不建议完全无敌）。
2. 当玩家持续攻击或靠近，先显示裂缝、环形扩散等可读预警。
3. 释放一次可躲避的地面冲击波，随后外壳短暂张开，暴露弱点。

**反制**：识别预警、越过 / 离开冲击范围、在张开窗口集中输出。玩家不应需要长时间等待它“终于肯开壳”。

**【原型参数】** 首个原型可**暂不制作**；若加入，建议只放一只，且不要与多重减速及密集延迟弹幕同时出现。

**表达**：封闭可以暂时回避问题，却使压力以突发方式返回。

### 4.4 敌人协作与公平性

| 组合 | 乐趣 | 禁止出现的情况 |
| --- | --- | --- |
| 迟滞者 + 迟滞者 | 观察悬停弹丸，规划横向位移 | 无预警的多方向弹幕封死全部通路 |
| 锚定者 + 迟滞者 | 判断目标优先级：先解控还是先输出 | 减速区域与弹幕同时必定命中玩家 |
| 退缩者 + 少量普通敌人 | 判断进攻 / 撤退窗口 | 精英长时间无敌，玩家只能被动挨打 |

核心原则：**“停滞”是敌人试图制造的威胁，不是游戏系统对玩家操作的惩罚。** 不做持续眩晕、长时间禁用移动 / 射击的控制链。

## 5. Boss 设计：Sloth — The Sleeping Colossus（沉眠巨像）

### 5.1 视觉与角色行为

**【共识】** Boss 必须直观看起来是**蜷缩着的巨人**：双臂环抱身体、低头、背部弓起，重量感极强。相比张牙舞爪的怪物，它更像一尊被迫醒来的大型几何雕像。

**【设计提案】**

- **主体**：白色 / 灰白色石质几何块构成的大型人形；不使用写实皮肤、肌肉纹理和复杂面部表情。
- **剪影**：始终保持“抱膝 / 蜷缩 / 护住胸口”的识别度；局部块体可在战斗中分离或开裂。
- **弱点**：环抱处的胸口 / 腹部存在微弱暖光，战斗中并非一直暴露。
- **动作**：不需要跑动与复杂的全身骨骼动画；可用肩背抬升、巨臂遮挡、局部旋转、震动与环境装置完成主要演出。
- **态度**：它不是主动炫耀力量的邪恶魔王；攻击更多像拒绝打扰、将玩家推远的防御反应。

**重要区别**：Boss 对玩家造成真实战斗威胁，并不等于他在道德上“邪恶”；第一次游玩时玩家仍能合理地认为它必须被清除。

### 5.2 场地与战斗目标

**【设计提案】** Boss 位于大环形结构中央，背后是停在半途的钟摆与悬浮石块。场地为可环绕的多边形平台，设少量高低错落的实体掩体。

- 视线必须经常能重新回到 Boss 的核心，不要通过复杂地形寻找攻击目标。
- 玩家站在边缘时应有明确地形边界，掉落不应成为主要惩罚。
- 在 Boss 场地布置 **Rest Zones**，但不让其无限回血或鼓励全程躲避战斗。
- Boss 击杀判定：原型中使用传统 HP 归零触发胜利演出；**是否真正“死亡”在叙事上刻意保持未明**。

### 5.3 Phase 1 — Do Not Disturb（不要惊扰）

**【原型参数】** 100%–50% HP，阶段比例可调整。

| 技能 | 动作与预警 | 玩家反制 |
| --- | --- | --- |
| Sleeping Breath / 沉睡之息 | Boss 胸腔起伏，地面生成缓慢扩张的冷色圆环，随后冲击 | 观察预警，离开圆环覆盖区或利用安全间隙 |
| Deferred Fall / 积压之物 | 数个悬浮几何块在玩家附近标出落点，延迟后依序坠落 | 持续换位，不停留在已标记位置 |
| Cocoon Guard / 封闭 | 巨人用手臂遮蔽胸口核心，周围两处简化节点亮起 | 射击节点打开攻击窗口，近战可以作为风险更高的替代打法【待验证】 |

**阶段感觉**：巨人几乎没有醒来，空间本身成为它的防御机制。玩家是在逼迫一个拒绝行动的存在回应自己。

### 5.4 Phase 2 — Forced Awakening（被迫苏醒）

**【原型参数】** 50%–0% HP。

- 巨人缓缓抬头，白色外壳出现裂缝；动作仍以保护自己、推开玩家为主。
- **Rejection Wave / 拒绝苏醒**：双臂张开前地面与声音充分预警，随后释放可通过距离、掩体或安全间隙规避的冲击波。
- **Stillness Pulse / 万物静止**：场地局部区域分批凝固；它改变可用位置，但**始终留下至少一条可辨认的安全路线**。
- 主要难点来自已有技能的**组合节奏**，不是叠加更多剥夺控制的效果。

**阶段结束**：巨人逐渐停止抵抗，庞大形体化为漂浮石片或失去活动能力；场地从静止进入“恢复运转”。不要用夸张恶魔惨叫或血腥处决破坏情感伏笔。

### 5.5 战斗公平性与数值约束

**先保证规则，再谈血量与 DPS。**

1. 所有大范围攻击必须有清楚的视觉 + 音频预警；白色地面上的圆环必须显著可读。
2. 不允许“沉滞领域 + 强制击退 + 延迟弹幕”形成必死连招；至少保留一个主动反制窗口。
3. Boss 不应常态无敌；保护核心时要提供可攻击节点或可靠的等待上限。
4. 保留枪械输出与近战风险回报，不要求必须携带某一种武器才能通关。
5. 如果休憩区存在，玩家可以利用它作为**战术选择**，但不应是唯一可行的胜利方式。
6. 推荐记录战斗死亡原因、每招命中率、每次无输出等待长度，以便调整。

## 6. Rest Zones：先让玩家体验“休息的价值”

### 6.1 呈现与功能

**【设计提案】** 休憩区是**温暖光晕中的简洁圆形区域**，没有床铺、营火等过于现实的道具。

- 进入后，若短时间内没有受到伤害，可逐步恢复少量护盾或临时防护值。
- 受到伤害或主动离开会中止恢复；冷却、次数或恢复上限防止无限拖延。
- 主要目的不只是帮助玩家通过 Boss，而是让玩家**亲自使用**这项机制。

**【原型参数】** 安全停留 2–3 秒开始恢复；具体恢复速度、是否需要完全停止移动、是否可以在 Boss 战使用均待测试。建议先采用“区域内、无伤害即恢复”，不要强迫玩家完全静止成靶子。

### 6.2 与 Pride 的关系

Pride 可以指出休憩区有帮助：

> “那里能恢复状态。利用它，我们才能更有效地继续前进。”

他没有说谎，也没有不允许玩家休息；他只是倾向于**以效率衡量休息的价值**。这使 Pride 的引导既可信，又为之后的观点分歧埋下伏笔。

## 7. Boss 战后演出：B + C

本节是本层叙事验证的重点。**不能只靠一段解释性字幕代替。**

### Sequence A：完成清除

1. HP 归零，玩家收到明确的战斗胜利反馈。
2. Sloth 身体逐渐碎裂 / 停止活动，原本停住的钟摆重新摆动。
3. Pride 真诚地肯定玩家：“做得好。我们终于摆脱停滞。”（**候选台词**）

### Sequence B：失去宁静

1. 钟摆**越摆越快**；悬浮结构开始不停运动，环境音从稀疏变为密集。
2. 玩家先前实际使用过的 Rest Zone 暖光逐渐熄灭。
3. 玩家返回原位置，可见原有恢复反馈已消失；建议让玩家有一小段**可自由观察**的时间。
4. 这不是惩罚性伤害关卡。尽量通过交互失效、画面与听觉对比表达损失，不强迫玩家承受持续掉血。

**关键测试：** 如果玩家没有主动注意这些变化，就需要强化可见路径、光照变化和先前的使用经验，而不是加一大段说明“现在不能休息了”。

### Sequence C：Rest Fragment（休息碎片）

1. 在原本蜷缩的巨人内部 / 残留位置出现温暖的金色几何碎片。
2. 玩家通过明确交互拾取。
3. **【候选能力】** 一定时间未受伤后缓慢恢复少量护盾，带有上限或触发冷却。与 Rest Zone 不同，它可随玩家进入后续战斗。
4. 通过简单即时反馈（护盾增长、柔和脉冲），使玩家理解这份能力**来自刚被自己击败的 Sloth**。
5. Pride 仍能从实用角度鼓励玩家收下它，例如：“即使是缺陷的残留，也能成为前进的工具。”（候选台词）

**情感终点：** 玩家拥有胜利感，同时产生一点不协调的疑问。**不揭晓完整真相，不强迫立即原谅 Sloth。**

## 8. 第一层完整的情绪与交互节奏

| 顺序 | 玩家主要动作 | 即时感受 | 潜在主题表达 |
| --- | --- | --- | --- |
| 1 | 进入冻结的回廊 | 新奇、目标明确 | 停滞需要被消灭 |

## 9. 原型制作优先级（按风险裁剪）

**目标不是完成一整层内容量，而是验证“战斗—胜利—失去—发现”的闭环。**

### P0：最小叙事 + 战斗验证

- 模块化白灰几何战场，含可辨认的地标、掩体和一处休憩区。
- **迟滞者**及可预判的延迟攻击。
- **锚定者**及有上限的减速领域。
- **沉眠巨像的基础蜷缩形态**，至少 2 种可反制技能 + 一个阶段变化。
- Boss 击败后的环境状态切换、Rest Zone 熄灭、Rest Fragment 拾取与能力反馈。
- Pride 最少量的引导台词（可先用字幕，配音以后考虑）。

### P1：验证成立后再加

- **退缩者**精英与外壳张开 / 冲击波。
- 完整的 Boss 技能组合、环境联动、第二阶段演出。
- 多房间间的奖励选择、轻量构筑 / Buff 交互。
- 更丰富的动态几何、音频与线条 Shader。

### 本阶段明确不做

- 七宗罪全部关卡；大量随机地图模板与长线局外成长。
- 复杂 Boss 全身动画、写实贴图、额外枪械重新建模套装。
- 大量分支剧情、全程配音、自动生成心理叙事。
- 为了叙事强行剥夺移动 / 射击操作的长控制链。

## 10. Godot 实现边界（不是代码规范）

**【建议】** 用简单组件分离表现与机制，降低未来迭代成本：

- **Enemy / Attack Pattern**：延迟弹丸状态（预警 → 悬停 → 释放 → 销毁）；锚定区域状态（预警 → 激活 → 消退）。
- **Boss State**：睡眠防御态、暴露窗口、阶段切换、战败态。
- **Level Phase**：PreBoss / BossActive / PostBoss；以事件驱动钟摆、Rest Zone 与环境音变化，而不是把剧情逻辑写进单个 Boss 脚本。
- **Rest Zone / Fragment**：共享恢复效果组件，区别在于区域触发或持有物触发；保持可配、可禁用。
- **Pride Dialogue**：通过事件触发、可跳过、不阻断射击与移动。
- **Visual Language**：尽量共用基础材质、几何模块、敌人预警特效与可复用的投影环。

以上是**组件边界建议**；不承诺当前代码库已经具备相应节点、资源或脚本。是否复用 Battlefield-Rouge 的系统，须经过单独技术评估。

## 11. 试玩与验收（Definition of Done for Prototype）

### 11.1 玩法可用性

- [ ] 玩家可以不依靠阅读文档理解基本目标，完成至少一次 P0 流程。
- [ ] 迟滞者的攻击方向与发射时机可读；测试者能通过走位或掩体主动规避。
- [ ] 锚定者的减速有明确开始与结束提示；不存在长期失控或叠加锁死。
- [ ] Boss 每种主要伤害都可以预见，并有合理躲避或反制方式。
- [ ] 白模场景中能区分敌人、危险区域、可通行地面与玩家武器轮廓。
- [ ] 不要求特定枪械或必须触发某个隐藏机制才能获胜。

### 11.2 叙事体验

试玩后**先问开放问题，不先解释主题**：

1. “你一开始认为自己来这里要做什么？”
2. “Boss 倒下以后，你注意到哪些环境或规则变化？”
3. “你觉得 Rest Fragment 与 Sloth 的关系是什么？”
4. “Pride 给你的印象是什么？你是否认同他的解释？”
5. “你是否觉得这一层的结局有点不寻常？为什么？”

判定重点并非测试者必须回答“应该接纳心魔”，而是他们是否**注意到实际损失**，并产生独立的解释或疑问。

### 11.3 制作质量

- [ ] 关键攻击有可读预警（图形、颜色 / 亮度、声音），不只依靠颜色区分。
- [ ] 恢复区域不会导致可无限拖延的最优打法。
- [ ] 玩法状态与战后场景状态不会相互污染；失败重开可正确复位。
- [ ] 至少一次由三名团队成员以外的试玩者完成盲测或观察式试玩（如可行）。
- [ ] 将高频死亡原因、误判与不理解的地方反馈至下一轮设计。
