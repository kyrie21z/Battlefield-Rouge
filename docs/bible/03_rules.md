# 03 规则

声明式事实。实现细节不写在这里。来源是 [Cut-001](../Cut-001.md) 及其勘误。数值是已锁定的临时默认，试玩后可调，做成配置。

## 已锁定

| 编号 | 状态 | 规则 |
| --- | --- | --- |
| D-001 | 已锁定（临时默认） | 完美打击窗口是命中时刻 ±150ms。成功：本次占点进度 ×1.5，并播放专用音效和闪光。失败：只记普通进度。验收用调试条或录屏（AC-04、AC-07）。 |
| D-002 | 已锁定 | 进关前选 1 条；每个小关结束再选 1 条，本局叠加；Boss 结束后不选。打完一局是 5 次。见 AC-06。 |
| D-003 | 已锁定（临时默认） | 小关先把当前波次打到 0，才允许锤砸（AC-02）。普通锤 +8%（AC-03）。增援不回退进度，只造成生命压力。100% 插旗并冲击波，本关结束（AC-05）。 |
| D-004 | 已锁定范围，效果 Design-TBD | 增益共 9 条：3 个流派各 3 条。不增加连携、进化或第二资源。 |

作废：±120ms、把 +12% 或 +20% 当成另一套配置。+12 个百分点只是 8%×1.5 的换算，配置旋钮是倍率 1.5。

Boss 与小关共用 D-001、D-003 的占点配置。清零之后才能砸，只约束小关。Boss 仍是一波城市核心。

## 解锁

与 Cut-001 的解锁顺序相同，由 AC-01 验收。

1. 新局只开放小关 1。
2. 小关 1 插旗结束 → 开放小关 2。
3. 小关 2 插旗结束 → 开放 Boss。
4. Boss 插旗 → 胜利，不选增益。
5. 阵亡：流派与本局解锁清空，从第 1 关重开。

关卡选择只切换已开放的关。
